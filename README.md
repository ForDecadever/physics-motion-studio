# Motion Studio

一个采用专业图形编辑器布局的二维物理运动模拟工具。当前版本为 `v1.5.4`，已形成可编辑、可模拟、可分析、可导出和可保存的 Web 版。

`v1.5.4` 使用 `schemaVersion: 16`。格式 15 无损迁移，格式 12、13、14 继续依次迁移；格式 11 或更早的旧图层结构仍明确拒绝。物体、地面、连接体、场、粒子源和根布尔结果处于同一根顺序；布尔结果自身是可展开父节点，递归包含真实来源。

## 当前已经具备

- React + TypeScript + Vite 工程和 Photoshop 风格编辑布局；
- PixiJS 二维画布、自适应米制网格、平移、画布缩放、选择、移动、旋转、对象等比缩放与吸附；
- 对象缩放使用 `S` 快捷键和四角手柄，可将小球、物块、地面和有限范围场作为多选整体缩放；地面显示与碰撞厚度保持不变；
- 创建统一的带电/可碰撞小球和物块；物块顶部可选矩形、钢笔、四分之一圆滑道、半圆槽、四分之一圆槽和可调角度三角形。非矩形预设生成可继续编辑的真实贝塞尔轮廓；钢笔轮廓闭合前不会生成实体，自交或退化草稿会保留并明确标出；
- 用“地面连接点工具”依次选择两个语义端点；自动过渡使用紧凑的对称裁剪和首个安全五次曲线，`≥179°` 的分离端点使用直线；重合反向端点以及切线连续的直线—曲线/曲线—曲线使用不增加绘制或碰撞几何的无形接缝；新地面的起点靠近未占用端点时可自动建立连接；
- 显示、碰撞采样和小球持续接触共用统一地面路径；连接只消除接缝假冲量，所需支持力为负时小球仍会自然脱离；
- 墙面和物块吸附使用移动物体的真实碰撞轮廓与正确方向支撑距离；非对称预设、凹形钢笔和布尔结果不会再按外接矩形留下错误间隙。候选在提交前拒绝实质穿透，网格、墙面与物块按最小修正距离稳定竞争，`Alt` 可临时绕过全部吸附；
- 绘制矩形、圆/扇形、钢笔自由形状或无限范围的匀强重力场、电场和磁场，并显示方向图例；
- 粒子源工具可创建点源或线源，向指定方向（线源垂直于线）发射带电离子；离子只受电场、磁场和带电物体的单向库仑力，不受重力、不碰撞，轨迹随时间延伸，线源按沿线位置用不同颜色区分；
- 场景面板用一棵统一树显示全部对象；布尔结果自身可展开真实来源，不再出现普通图层、布尔容器和重复“布尔结果”行。左侧一次性“布尔组合”按钮会按根顺序组合两个兼容选择，否则创建空节点；
- 布尔节点按视觉上下顺序组合两个物体或两个同类有限场并允许无环嵌套。位置与角度可整体编辑；质量、电荷、摩擦、弹性、线速度和角速度在首次编辑前保留来源行为，首次编辑后仅对应项目切换为结果级整体覆盖；
- 布尔解析使用稳定内容修订缓存；整棵子树统一平移或旋转时直接变换缓存结果，拖动和松手均不重新执行 CSG。普通实体与多个根布尔结果可作为同一选择组移动；从展开场景树选择来源后可单独移动、旋转和缩放；
- 钢笔物块和钢笔有限场的控制棒默认镜像联动；按住 `Alt` 拖动时只修改当前控制棒，`Alt+左键单击`锚点可折叠为零控制棒拐角，再次点击精确恢复；
- 计算物体间库仑力，并可在场景属性中关闭或开启（新场景默认关闭）；
- 绳、杆和弹簧可连接物体、普通地面或地面连接段；弹簧还可使用固定世界点或独立自由端。新建连接器点击小球或物块时默认连接物体中心；杆的 A/B 端可分别设为自由或固定转动。绳开启碰撞时质量自动补足到至少 `0.001 kg`，局部多段接触、分段/长距离张力和整绳弧长约束交替求解：绳会在撞击处弯曲，并能围绕圆球形成连续包络；小质量下也不会持续拉长。关闭碰撞后绳恢复零质量理想约束；
- 绳和杆的物体锚点始终夹在碰撞轮廓内；弹簧锚点拖出物体后会转换为固定世界点，重新拖到物体或地面可再次连接。弹簧固定为零质量并关闭普通碰撞；解除 A/B 端后，自由端变为可压缩储能的轴向软端帽，可反弹小球、物块和全部双面地面，一端连接物体时会随物体平移和旋转。弹簧停止时始终显示场景端点，首个物理步才按原长回拉或释放预压储能；
- 在右侧编辑位置、角度、尺寸、质量、初速度、初角速度、旋转约束、摩擦系数、弹性系数和 CCD；
- Rapier 2D 刚体碰撞在独立 Web Worker 中运行，不会阻塞界面；
- 固定 `1/120 s` 物理步长，以及播放、暂停、单步、倍速和重置；
- 圆弧和贝塞尔曲线自适应离散；每块地面在 Rapier 中使用原生双面 `polyline` 碰撞体。连接关系裁剪出的直线仍只保留两个解析端点，不会因人为插入共线采样点产生错误碰撞法线；
- 高速小球会按单步位移与半径自动启用连续碰撞检测；无摩擦、完全弹性地碰撞直线、圆弧或连接过渡时，使用解析地面扫掠恢复首次撞击法线，并按外力实际做功保持机械能，避免错误反向及随机增能或减能；
- 接触摩擦系数和弹性系数均按几何平均合成，分别为 `sqrt(μ₁ × μ₂)` 与 `sqrt(e₁ × e₂)`；
- 选中运行中的物体时显示轨迹、速度和物理步内平均合外力；
- 图像区可同时建立最多 8 张独立坐标系卡片，每张卡片可设置横纵轴、添加多物体曲线并独立缩放和查看十字提示；
- 坐标轴既可选择时间、位置、速度、加速度、角度、力和动能等预设量，也可使用经过量纲检查的安全公式和 `@A.x` 形式的跨物体引用；
- 同一份完整物体状态按模拟时间 `60 Hz` 共享记录最近 `300 s`，避免多张图重复保存数据；曲线可独立设置颜色、实线/虚线/点线和 `1～6 px` 粗细；
- 单张坐标系可导出宽表 CSV，全部坐标系可导出长表 CSV；图表配置随场景保存，运行采样不写入场景文件；
- 文件菜单可把最近最多 `300 s` 的已记录模拟导出为 GIF 动图；统一时间轴可裁剪区间并拖动播放头，预览框明确显示最终裁切范围，还可调整分辨率、帧率、`0.25×～4×` 成片倍速，以及网格、透明背景、物体轨迹、速度和合力；带质量或带碰撞连接器的运行节点也使用同一份历史几何；
- 图表刻度、十字坐标和提示统一限制为最多六位有效数字，极大或极小值使用科学计数法；常量序列使用稳定、非零且量化的轴范围，绘图区不会因浮点噪声反复伸缩；
- 场景树节点通过双击名称重命名，并通过拖拽改变根顺序；复制完整端点集合时会自动带上绳、杆、弹簧和地面连接点，并把关系重定向到副本；
- 工具、场景、属性和图像面板支持左、右、底部停靠、应用内浮动、缩放、关闭与恢复；布局只保存在本机，播放栏始终固定可见；
- 新建、打开、直接保存/另存或下载 `.motion.json` 场景，写入后执行 SHA-256 内容校验；
- IndexedDB 自动草稿和意外刷新恢复；格式 15 严格校验统一场景树、布尔整体覆盖、钢笔物块轮廓和折叠节点，格式 14 无损迁移、格式 12/13 依次迁移，旧图层结构明确拒绝读取；
- 复制/粘贴、播放快捷键、键盘可调面板、减少动态效果和明确焦点样式；
- ESLint、Prettier、TypeScript、Vitest、Playwright 视觉回归和物理性能基准。

物理验证方法与误差边界记录在 [docs/PHYSICS_VALIDATION.md](./docs/PHYSICS_VALIDATION.md)，性能结果记录在 [docs/PERFORMANCE_BASELINE.md](./docs/PERFORMANCE_BASELINE.md)。

## 第一次运行


安装依赖：

```powershell
pnpm install
```

启动开发界面：

```powershell
pnpm dev
```

成功时会显示 `http://127.0.0.1:4173/`。终止服务器时按 `Ctrl+C`。

## 桌面版（Tauri）

本仓库同时包含 Windows x64 桌面版封装（`src-tauri/`）。桌面版使用原生文件对话框、`.motionstudio` 文件关联、单实例、最近文件和原生窗口菜单。

开发调试（需要已安装 Rust 与 MSVC 工具链）：

```powershell
pnpm desktop:dev
```

构建未签名、每用户安装的 NSIS 安装包：

```powershell
pnpm desktop:build
```

安装包生成在 `src-tauri/target/x86_64-pc-windows-msvc/release/bundle/nsis/`。构建脚本默认目标为 `x86_64-pc-windows-msvc`。

## 如何搭建第一个运动场景

1. 用“地面工具”拖出地面；
2. 用“物体工具”放置小球或物块；
3. 用“场工具”画出覆盖物体运动范围的重力场；
4. 选中物体，在右侧输入初速度等参数；
5. 点击底部播放按钮。模拟开始后编辑会锁定，点击重置回到 `0 s` 后可继续修改。

## 检查命令

完整检查：

```powershell
pnpm check
```

真实浏览器交互检查：

```powershell
pnpm e2e
```

成功时会看到全部测试通过。第一次在新电脑上运行浏览器检查前，需要先执行 `pnpm e2e:install`。

物理性能基准：

```powershell
pnpm benchmark
```

## 项目结构

下表覆盖整理后仓库根目录保留的每一项。测试源码只用于开发验收，不会被 Vite 打进生产页面。

| 路径 | 用途 |
| --- | --- |
| `.git/` | Git 版本历史与标签，只由 Git 管理。 |
| `docs/` | 物理验证、性能基线和架构决策记录；`docs/adr/` 保存每项重要设计为何这样实现。 |
| `e2e/` | Playwright 真实浏览器交互测试与视觉快照。 |
| `scripts/` | 项目维护脚本；当前的 `run-e2e.mjs` 负责在 Windows 上可靠启动并运行浏览器测试。 |
| `src/` | React 界面、编辑器、场景模型、渲染器和物理核心源码，以及就近放置的单元/性能测试。 |
| `.editorconfig` | 统一编辑器的缩进、换行和字符集。 |
| `.gitattributes` | 统一 Git 文本文件换行规则。 |
| `.gitignore` | 排除依赖、构建结果、测试报告、缓存和日志。 |
| `.prettierignore` | 告诉 Prettier 哪些生成文件无需格式化。 |
| `.prettierrc.json` | Prettier 代码格式配置。 |
| `CONTRIBUTING.md` | 开发、测试和 Git 提交约定。 |
| `PROJECT_SPEC.md` | 产品功能、物理口径、架构边界和阶段验收规范。 |
| `README.md` | 项目简介、运行方法和目录说明。 |
| `eslint.config.js` | ESLint 静态代码检查规则。 |
| `index.html` | Vite Web 页面的 HTML 入口。 |
| `package.json` | 版本号、脚本命令和直接依赖声明。 |
| `playwright.config.ts` | 浏览器端到端测试配置。 |
| `pnpm-lock.yaml` | 锁定完整依赖树，保证不同电脑安装结果一致。 |
| `tsconfig.json` | TypeScript 公共配置入口。 |
| `tsconfig.app.json` | 浏览器应用源码的 TypeScript 配置。 |
| `tsconfig.node.json` | Vite、测试等 Node 工具文件的 TypeScript 配置。 |
| `vite.config.ts` | Vite 构建和 Vitest 测试配置。 |

`src/` 内部按职责拆分：

| 路径 | 用途 |
| --- | --- |
| `src/app/` | 应用外壳、顶层菜单与全局快捷键。 |
| `src/editor/` | 编辑命令、几何计算、吸附和待提交输入协调。 |
| `src/features/` | 画布、工具栏、场景树、属性、图表、GIF 导出和可停靠工作区等界面功能。 |
| `src/persistence/` | 场景打开、保存、校验和草稿恢复。 |
| `src/physics/client/` | 主线程与物理 Worker 之间的控制器。 |
| `src/physics/core/` | 可独立测试的 Rapier 世界、地面路径、碰撞、场力和连接约束。 |
| `src/physics/worker/` | 后台固定步模拟循环、采样记录和消息协议。 |
| `src/renderer/` | PixiJS 场景、网格和编辑辅助图形渲染。 |
| `src/scene/` | 场景数据类型、实体工厂、校验、版本迁移和选择查询。 |
| `src/stores/` | 文档、编辑器、运行时和工作区布局状态。 |
| `src/styles/` | 全局颜色、尺寸和层级样式变量。 |
| `src/types/` | 第三方或跨模块补充类型声明。 |
| `src/main.tsx` | React 应用启动入口。 |
