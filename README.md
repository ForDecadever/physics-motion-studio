# Motion Studio

一个采用专业图形编辑器布局的二维物理运动模拟工具。当前版本为 `v1.6.2`，已形成可编辑、可模拟、可分析、可导出和可保存的 Web 版，并提供 Windows x64 桌面版（Tauri v2）。

当前发布版使用 `schemaVersion: 22`。格式 21 会为粒子源补上默认关闭的“同时发射”，保持旧场景逐个发射；格式 20 继续确定性补齐粒子源密度、连续参数并迁移电场和力公式，格式 12～19 依次迁移，格式 11 或更早的旧图层结构仍明确拒绝。

## 当前已经具备

- React + TypeScript + Vite 工程和 Photoshop 风格编辑布局；
- PixiJS 二维画布、自适应米制网格、平移、画布缩放、选择、移动、旋转、对象等比缩放与吸附；
- 对象缩放使用 `S` 快捷键；四角保持等比缩放，矩形/钢笔物块、直线/贝塞尔地面、矩形/钢笔有限场及对应布尔结果另有四边中点单轴缩放；
- 创建可独立设置颜色的带电/可碰撞小球和物块；矩形从一个角拖到对角生成，物块顶部还可选钢笔、四分之一圆滑道、半圆槽、四分之一圆槽和可调角度三角形；
- 用“地面连接点工具”依次选择两个语义端点；自动过渡使用紧凑的对称裁剪和首个安全五次曲线，`≥179°` 的分离端点使用直线；重合反向端点以及切线连续的直线—曲线/曲线—曲线使用不增加绘制或碰撞几何的无形接缝；新地面的起点靠近未占用端点时可自动建立连接；
- 显示、碰撞采样和小球持续接触共用统一地面路径；连接只消除接缝假冲量，所需支持力为负时小球仍会自然脱离；
- 墙面和物块吸附使用移动物体的真实碰撞轮廓与正确方向支撑距离；非对称预设、凹形钢笔和布尔结果不会再按外接矩形留下错误间隙。候选在提交前拒绝实质穿透，网格、墙面与物块按最小修正距离稳定竞争，`Alt` 可临时绕过全部吸附；
- 绘制矩形、圆/扇形、钢笔自由形状或无限范围的匀强重力场、电场和磁场，并显示方向图例；
- 重力场和磁场大小、电场 X/Y 分量均可使用含模拟时间 `t` 与全局变量的安全公式；任一分量在某一步得到非有限结果时只跳过对应场并给出去重警告；
- 力工具可把世界方向的力锚定到普通物体或根布尔物体的局部点；力大小和以度显示的方向可分别使用含 `t` 的公式，偏心力会产生真实转矩；
- 编辑菜单的“全局变量…”可按顺序定义 `a=10`、`b=a/2` 等变量；场景属性中的受控数值输入均可使用 `3a`、`a/10` 等公式，并保留上下箭头、显示单位步进、当前解析值和可撤销的绑定清除；
- 粒子源工具可创建点源或线源；点源密度可在 `0.01～10 个/度` 内设置，`180° × 3 个/度` 精确生成 `540` 个粒子，整圆最多生成 `3600` 个不重复方向；两种源均可按确定性时间表逐个或整批同时连续发射，默认间隔 `1 s`、寿命 `60 s`，新建粒子默认电荷为 `1 C`；
- 记号笔、直尺和量角器可在播放、暂停和停止时使用，并作为不参与物理的测量实体保存和撤销；测力计是会话内探针，可在物体所选点实时分解重力、场力和外加力，并按名称分别显示每根绳、杆、弹簧及每个地面/物体接触的推导作用力和箭头；
- 场景面板用一棵统一树显示全部对象；布尔结果自身可展开真实来源，不再出现普通图层、布尔容器和重复“布尔结果”行。左侧一次性“布尔组合”按钮会按根顺序组合两个兼容选择，否则创建空节点；
- 布尔节点支持并集、交集和差集，并按视觉上下顺序组合两个物体或两个同类有限场。布尔物体按来源颜色分区绘制；场布尔可独立切换统一场强，并在真实结果区域显示方向图例；
- 布尔解析使用稳定内容修订缓存；整棵子树统一平移或旋转时直接变换缓存结果，拖动和松手均不重新执行 CSG。普通实体与多个根布尔结果可作为同一选择组移动；从展开场景树选择来源后可单独移动、旋转和缩放；
- 钢笔物块和钢笔有限场的控制棒默认镜像联动；按住 `Alt` 拖动时只修改当前控制棒，`Alt+左键单击`锚点可折叠为零控制棒拐角，再次点击精确恢复；
- 计算物体间库仑力，并可在场景属性中关闭或开启（新场景默认关闭）；
- 绳、杆和弹簧可连接物体、普通地面或地面连接段；弹簧还可使用固定世界点或独立自由端。新建连接器点击小球或物块时默认连接物体中心；杆的 A/B 端可分别设为自由或固定转动。绳开启碰撞时质量自动补足到至少 `0.001 kg`，局部多段接触、分段/长距离张力和整绳弧长约束交替求解：绳会在撞击处弯曲，并能围绕圆球形成连续包络；小质量下也不会持续拉长。关闭碰撞后绳恢复零质量理想约束；
- 绳和杆的物体锚点始终夹在碰撞轮廓内；弹簧锚点拖出物体后会转换为固定世界点，重新拖到物体或地面可再次连接。弹簧固定为零质量并关闭普通碰撞；解除 A/B 端后，自由端变为可压缩储能的轴向软端帽，可反弹小球、物块和全部双面地面，一端连接物体时会随物体平移和旋转。弹簧停止时始终显示场景端点，首个物理步才按原长回拉或释放预压储能；
- 在右侧编辑位置、角度、尺寸、质量、初速度、初角速度、旋转约束、摩擦系数、弹性系数和 CCD；
- Rapier 2D 刚体碰撞在独立 Web Worker 中运行，不会阻塞界面；
- 固定 `1/120 s` 物理步长，以及播放、暂停、单步、倍速和重置；
- 圆弧和贝塞尔曲线自适应离散；每块地面在 Rapier 中使用原生双面 `polyline` 碰撞体。连接关系裁剪出的直线仍只保留两个解析端点，不会因人为插入共线采样点产生错误碰撞法线；
- 高速小球会按单步位移与半径自动启用连续碰撞检测；无摩擦、完全弹性地碰撞直线、圆弧或连接过渡时，使用解析地面扫掠恢复首次撞击法线，并按外力实际做功保持机械能，避免错误反向及随机增能或减能；
- 接触摩擦系数和弹性系数均按几何平均合成，分别为 `sqrt(μ₁ × μ₂)` 与 `sqrt(e₁ × e₂)`；
- 普通地面可开启沿解析路径正向或反向运行的传送带并设置表面速度；反向标记点从路径末端出发，直线、圆弧、贝塞尔及连接过渡使用同一切线方向，只有非零摩擦接触会被带动；
- 粒子在匀强磁场中按解析圆弧同步推进位置和速度，跨越有限场边界时只对该固定步局部细分；线源进入等半径圆形磁场的聚焦误差受专项回归约束；
- 选中运行中的物体时显示轨迹、速度和物理步内平均合外力；物体与离子轨迹使用误差抽稀的定长分块环形缓冲，长时间播放不会反复复制完整历史；
- 图像区可同时建立最多 8 张独立坐标系卡片，每张卡片可设置横纵轴、添加多物体曲线并独立缩放和查看十字提示；
- 坐标轴既可选择时间、位置、速度、加速度、角度、力和动能等预设量，也可使用经过量纲检查的安全公式和 `@A.x` 形式的跨物体引用；
- 同一份完整物体状态按模拟时间 `60 Hz` 共享记录最近 `300 s`，避免多张图重复保存数据；曲线可独立设置颜色、实线/虚线/点线和 `1～6 px` 粗细；
- 单张坐标系可导出宽表 CSV，全部坐标系可导出长表 CSV；图表配置随场景保存，运行采样不写入场景文件；
- 文件菜单可把已记录模拟导出为 GIF 动图；统一时间轴可裁剪区间并拖动播放头，预览框明确显示最终裁切范围，还可调整分辨率、帧率、`0.25×～4×` 成片倍速，以及网格、透明背景、物体轨迹、速度和合力；动态粒子按稳定 ID 记录出生与到期，连续粒子只显示当前位置；粒子不再有 512 个导出上限，记录达到公开的 `512 MiB` 遥测预算时淘汰最旧帧并提示实际可导出范围；
- 图表刻度、十字坐标和提示统一限制为最多六位有效数字，极大或极小值使用科学计数法；常量序列使用稳定、非零且量化的轴范围，绘图区不会因浮点噪声反复伸缩；
- 场景树节点通过双击名称重命名，并通过拖拽改变根顺序；复制完整端点集合时会自动带上绳、杆、弹簧和地面连接点，并把关系重定向到副本；
- 工具、场景、属性和图像面板支持左、右、底部停靠、应用内浮动、缩放、关闭与恢复；单列窄工具栏保留滚动，多列工具栏按行优先均衡分配为相差不超过一个工具的列，布局只保存在本机，播放栏始终固定可见；
- 顶栏“设置”已经并入“编辑 → 设置…”，可管理网格/吸附和新建物体、地面、场、粒子源、力及记录的默认值；软件固定使用暗色主题，旧主题偏好会迁移为暗色；偏好只保存在本机，不改写当前场景；“帮助 → 软件说明”提供完整操作与限制，并可打开或下载 38 页中文 PDF 手册；
- 新建、打开、直接保存/另存或下载 `.motion.json` 场景，写入后执行 SHA-256 内容校验；
- IndexedDB 自动草稿和意外刷新恢复；格式 22 严格校验统一场景树、测量标注、受控数值属性表达式、电场分量、外加力、连续粒子批量参数、布尔整体覆盖、颜色、钢笔轮廓和地面传送带，格式 12～21 确定性迁移，旧图层结构明确拒绝读取；
- 复制/粘贴、播放快捷键、键盘可调面板、减少动态效果和明确焦点样式；
- ESLint、Prettier、TypeScript、Vitest 和物理性能基准。

完整中文图文说明见应用内“帮助 → 软件说明”，可运行 `python scripts/generate-manual.py` 生成 PDF 手册。物理验证方法与误差边界记录在 [docs/PHYSICS_VALIDATION.md](./docs/PHYSICS_VALIDATION.md)，性能结果记录在 [docs/PERFORMANCE_BASELINE.md](./docs/PERFORMANCE_BASELINE.md)。

## 第一次运行


安装依赖：

```powershell
pnpm install
```

启动开发界面：

```powershell
pnpm dev
```

成功时会显示 `http://127.0.0.1:4173/`。终止服务器时按 `Ctrl+C`。

## 桌面版（Tauri）

本仓库同时包含 Windows x64 桌面版封装（`src-tauri/`）。桌面版使用原生文件对话框、`.motionstudio` 文件关联、单实例、最近文件和原生窗口菜单。

开发调试（需要已安装 Rust 与 MSVC 工具链）：

```powershell
pnpm desktop:dev
```

构建未签名、每用户安装的 NSIS 安装包：

```powershell
pnpm desktop:build
```

安装包生成在 `src-tauri/target/x86_64-pc-windows-msvc/release/bundle/nsis/`。构建脚本默认目标为 `x86_64-pc-windows-msvc`。

## 如何搭建第一个运动场景

1. 用“地面工具”拖出地面；
2. 用“物体工具”放置小球或物块；
3. 用“场工具”画出覆盖物体运动范围的重力场；
4. 选中物体，在右侧输入初速度等参数；
5. 点击底部播放按钮。模拟开始后编辑会锁定，点击重置回到 `0 s` 后可继续修改。

## 检查命令

完整检查：

```powershell
pnpm check
```

物理性能基准：

```powershell
pnpm benchmark
```

1000 秒普通场景与 100 秒复杂场景的长时间稳定性基准：

```powershell
pnpm benchmark:long
```
