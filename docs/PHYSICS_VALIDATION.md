# 第一版物理正确性验证（阶段 4）

更新日期：2026-07-21

## 1. 验证目标

阶段 3 的验收标准不是“动画看起来像真的”，而是相同初始条件下，刚体、场和连接器的数值结果应在明确误差范围内符合经典力学，并且运行结果可复现。

内部统一采用 SI 单位：长度为米 `m`、质量为千克 `kg`、时间为秒 `s`、角度为弧度 `rad`。物理核心固定以 `Δt = 1/120 s` 前进；播放倍速只改变单位现实时间内执行的固定步数，不改变 `Δt`。

## 2. 自动验证项目

| 项目 | 对照规律或目标 | 自动验收条件 |
| --- | --- | --- |
| 固定步长 | `t = N × Δt` | 120 步后模拟时间为 1 秒，误差小于 `1e-12 s` |
| 自由落体 | `v = gt`、`y = y₀ + 1/2 gt²` | 速度与解析解误差小于 `0.001 m/s`；位置允许固定步长积分误差 |
| 斜抛运动 | `x = v₀x t`、`y = v₀y t + 1/2 gt²` | 水平速度保持不变，水平和竖直位置落在规定容差内 |
| 质量无关性 | 同一重力加速度下不同质量物体运动相同 | `0.5 kg` 与 `8 kg` 物体的位置和速度在 6 位小数内一致 |
| 完全弹性正碰 | 动量守恒、动能守恒 | 等质量物体交换速度；总动量和总动能落在规定容差内 |
| 弹性合成 | `e = max(e₁, e₂)` | 一个物体 `e=1`、另一个 `e=0` 时仍按完全弹性碰撞 |
| 滑动摩擦 | `a ≈ μg` | 水平物块的速度变化与理论值在 0.1 数量级内一致 |
| 静止接触 | 支持力与重力平衡 | 小球在水平地面稳定于半径高度，竖直速度小于 `0.01 m/s` |
| 曲面接触 | 圆弧/贝塞尔离散面不下沉、不穿透 | 小球在最低点持续 3 秒后仍稳定接触 |
| 无摩擦圆弧 | 持续接触时机械能守恒 | 小球运动 12 秒后的机械能漂移小于可用机械能的 `0.5%` |
| 曲线精度 | 圆弧弦高误差、贝塞尔平坦度误差受控 | 默认最大几何误差 `0.002 m`，最大线段长度 `0.1 m` |
| 单面碰撞 | 背面穿过、法线面阻挡 | 同一条线在 `normal` 与 `both` 模式下得到相反的背面碰撞结果 |
| CCD | 高速物体连续碰撞检测 | `100 m/s` 小球不会穿过零厚度直线地面 |
| 可复现性 | 相同输入和步数得到相同输出 | 两个独立物理世界运行 240 步后的完整状态严格相等 |
| 场区域 | 旋转矩形、圆形、多边形包含判断 | 内部、外部和边界点均按预期分类 |
| 匀强电场 | `a = qE/m` | 运行 1 秒后的二维速度与解析值在 4 位小数内一致 |
| 匀强磁场 | `r = mv/|qB|`，磁场不做功 | 四分之一周期后位置符合理论半径，速率在 8 位小数内不变 |
| 点电荷对 | 库仑定律、牛顿第三定律 | 同号排斥；两物体的力和速度变化大小相等、方向相反 |
| 单摆 | `T ≈ 2π√(L/g)` | 小角度运行一个理论周期后回到初始侧，绳长不超限 |
| 绳 | 只限制最大长度 | 端点向外运动后距离不超过最大长度 `0.01 m` |
| 杆 | 同时承受拉力和推力 | 运行 2 秒后端点距离在 6 位小数内等于设定长度 |
| 弹簧振子 | 双质量无阻尼周期 | 运行一个解析周期后相对距离回到初始值的规定容差内 |
| 图表派生量 | `a = Δv/Δt`、`Eₖ = 1/2mv² + 1/2Iω²` | 加速度、合外力与重力解析值一致，总动能等于平动与转动动能之和 |
| 图层语义 | 隐藏/锁定只影响编辑显示 | 隐藏并锁定图层后，物体仍按相同重力规律运动 |

## 3. 数值实现约定

- 世界自身重力设为零，匀强重力场以 `F = mg` 的形式逐步施加，因此不同质量物体得到相同加速度；
- 匀强电场按 `F = qE` 累加；无电荷物体不受电场影响；
- 二维磁场按 `Fx = q·vy·Bz`、`Fy = -q·vx·Bz` 确定方向，并用精确速度旋转保持磁场不做功；
- 点电荷使用 `k = 8.9875517923×10⁹ N·m²/C²` 成对计算，最小计算距离取两物体半径之和；
- 绳使用 Rapier 最大长度约束；杆使用质量加权的位置和速度投影；弹簧使用胡克定律与轴向阻尼；
- 每步显示的合外力由同一物理步的动量变化 `m·Δv/Δt` 得到，包含碰撞和约束的平均效果；
- 图表加速度直接使用上述合外力除以质量；动能使用 Rapier 的实际质量和有效转动惯量，不使用渲染帧差分；
- 图表按模拟时间采样，默认频率为 `60 Hz`；Worker 把多个样本批量发给主线程，因此 4× 倍速不会降低每模拟秒的样本数；
- 物体质量直接写入碰撞体，由 Rapier 根据形状和质量自动计算转动惯量；
- UI 摩擦系数先存为 `sqrt(μ)`，再使用 Rapier 的乘法合成规则，从而让接触对得到 `sqrt(μ₁ × μ₂)`；
- 弹性使用最大值合成；
- 圆弧按弦高误差自适应细分，贝塞尔曲线按控制点到弦的距离递归细分；
- 圆形物体与圆弧面的摩擦系数都为零且保持单一接触时，使用解析圆弧与 velocity Verlet 推进切向运动；首次碰撞仍由 Rapier 按弹性系数处理，所需支持力为负时物体会脱离曲面；
- 单面地面以曲线绘制方向的左法线为正面；“翻转法线”通过反转采样点顺序实现；
- 物理线程最多追赶 16 个固定步，设备长期跟不上时会丢弃过期追赶量并发出警告，避免界面永久卡死。
- 单面地面先用保守包围盒筛选可能接近的刚体，再计算精确有符号距离；这只减少无接触物体的检查，不改变接触判定。

## 4. 已知边界

- 这是实时数值模拟，不是符号计算器；长时间、高刚度、极端质量比和大量高速碰撞仍会积累数值误差；
- 一般圆弧/贝塞尔碰撞仍是误差受控的折线近似；只有无摩擦圆形物体在圆弧上的持续单一接触使用解析约束；
- 点电荷成对计算目前为 `O(n²)`，适合教学场景中的少量电荷；大量电荷的空间加速算法留待性能数据证明有需要时实现；
- 杆的非中心锚点通过迭代位置/速度投影保持长度，极端质量比或多重闭环杆系仍可能需要更多求解迭代；
- 同一步内同时存在强电场、强磁场和碰撞时采用固定步长分裂推进，仍有 `Δt` 量级的数值误差；
- 图表默认最多 10 条曲线、60 样本/模拟秒、最近 300 秒；到达上限会丢弃最旧记录并提示。画布轨迹独立保留最近 1800 个渲染采样点。

任何物理核心修改都必须重新运行 `pnpm test` 和 `pnpm e2e`，并为新规律或新边界条件增加测试。
