# Motion Studio 0.8 物理正确性验证

更新日期：2026-07-28

## 1. 验证目标

0.8 版本的验收标准不是“动画看起来像真的”，而是相同初始条件下，刚体、统一地面路径、场和连接器的数值结果应在明确误差范围内符合经典力学，并且运行结果可复现。

内部统一采用 SI 单位：长度为米 `m`、质量为千克 `kg`、时间为秒 `s`、角度为弧度 `rad`。物理核心固定以 `Δt = 1/120 s` 前进；播放倍速只改变单位现实时间内执行的固定步数，不改变 `Δt`。

## 2. 自动验证项目

| 项目 | 对照规律或目标 | 自动验收条件 |
| --- | --- | --- |
| 固定步长 | `t = N × Δt` | 120 步后模拟时间为 1 秒，误差小于 `1e-12 s` |
| 自由落体 | `v = gt`、`y = y₀ + 1/2 gt²` | 速度与解析解误差小于 `0.001 m/s`；位置允许固定步长积分误差 |
| 斜抛运动 | `x = v₀x t`、`y = v₀y t + 1/2 gt²` | 水平速度保持不变，水平和竖直位置落在规定容差内 |
| 质量无关性 | 同一重力加速度下不同质量物体运动相同 | `0.5 kg` 与 `8 kg` 物体的位置和速度在 6 位小数内一致 |
| 完全弹性正碰 | 动量守恒、动能守恒 | 等质量物体交换速度；总动量和总动能落在规定容差内 |
| 弹性合成 | `e = sqrt(e₁ × e₂)` | `e₁=0.25`、`e₂=1` 时接触恢复系数约为 `0.5`；任一侧为 `0` 时不主动反弹 |
| 滑动摩擦 | `a ≈ μg` | 水平物块的速度变化与理论值在 0.1 数量级内一致 |
| 静止接触 | 支持力与重力平衡 | 小球在水平地面稳定于半径高度，竖直速度小于 `0.01 m/s` |
| 曲面接触 | 圆弧/贝塞尔离散面不下沉、不穿透 | 小球在最低点持续 3 秒后仍稳定接触 |
| 无摩擦圆弧 | 持续接触时机械能守恒 | 小球运动 12 秒后的机械能漂移小于可用机械能的 `0.5%` |
| 圆轨道脱离 | 单侧支持力不能拉住物体 | 完整圆轨道顶部的低速小球在低于临界速度时离开圆周，后续不被重新投影回轨道 |
| 圆弧持续约束 | 不因折线/解析阈值切换产生假冲量 | `R=3 m`、球半径 `0.5 m`、`v=8 m/s` 的无重力完整圆周中，加速度与 `25.6 m/s²` 的误差小于 `1%`，接触状态不闪烁 |
| 曲面接触资格 | 只由真实接触激活并按支持力延续 | 主动分离、所需支持力为负、未连接端点或非法偏置曲率立即解除；预测接触不能重新激活约束 |
| 曲线精度 | 圆弧弦高误差、贝塞尔平坦度误差受控 | 默认最大几何误差 `0.002 m`，最大线段长度 `0.1 m` |
| 地面显示隔离 | 显示路径与碰撞采样相互独立 | 先绘制直线再绘制圆弧时二者之间无显示连线，也不产生额外碰撞面 |
| 双面地面碰撞 | 一个原生折线碰撞体同时阻挡正反两侧 | 小球从同一地面的两侧接近都发生碰撞；每块地面只创建一个 Rapier `polyline` 碰撞体 |
| 地面连接有效性 | 两个非退化语义端点可以相隔一定距离 | 每端点只被引用一次；`≤1°` 明确失效，`1°～179°` 只接受安全五次过渡，`≥179°` 只生成端点间直线 |
| 地面接缝交接 | 可见五次过渡不产生接缝冲量 | 无摩擦小球双向通过 `90°` 与 `150°` 平滑过渡时速度跳变小于 `0.5%`；极端角不得生成发卡或环形路径 |
| 物块接缝接触 | 曲线采样内部端帽不产生横向假冲量 | `0.4 m × 0.4 m` 物块以 `4 m/s` 双向通过无摩擦 `90°` 连接时，最大单步加速度小于 `100 m/s²`，最低速率大于 `3.5 m/s` |
| 墙面端点吸附 | 候选距离使用真实欧氏最近距离 | 鼠标控制的物体沿地面切线远离端点后不吸附，阈值内吸附后外轮廓与端点相切 |
| CCD | 高速物体连续碰撞检测 | `100 m/s` 小球不会穿过零厚度直线地面 |
| 可复现性 | 相同输入和步数得到相同输出 | 两个独立物理世界运行 240 步后的完整状态严格相等 |
| 场区域 | 旋转矩形、圆/扇形、自由多边形包含判断 | 内部、外部和边界点均按预期分类；正负圆心角方向正确 |
| 匀强电场 | `a = qE/m` | 运行 1 秒后的二维速度与解析值在 4 位小数内一致 |
| 匀强磁场 | `r = mv/|qB|`，磁场不做功 | 四分之一周期后位置符合理论半径，速率在 8 位小数内不变 |
| 点电荷对 | 库仑定律、牛顿第三定律 | 同号排斥；两物体的力和速度变化大小相等、方向相反 |
| 单摆 | `T ≈ 2π√(L/g)` | 小角度运行一个理论周期后回到初始侧，绳长不超限 |
| 绳 | 只限制最大长度 | 端点向外运动后距离不超过最大长度 `0.01 m` |
| 物体旋转锁 | Rapier 刚体转动自由度约束 | 小球和物块在非零初角速度、偏心弹簧、摩擦曲面和碰撞条件下角度漂移小于 `1e-6 rad`，角速度与转动动能始终为 `0` |
| 自由端杆 | 双边锚点距离约束 | 拉伸、压缩、不同质量、非中心锚点、单/双端锁转、共享物体、链和闭环中杆长误差小于 `1e-5 m` |
| 自由端杆长期稳定性 | 理想约束不做功并守恒动量 | 无外力双体杆运行 `300 s`，总机械能相对漂移小于 `0.5%`，质心速度和总角动量保持不变 |

| 弹簧振子周期 | 双质量无阻尼解析周期 | 运行一个解析周期后相对距离回到初始值的规定容差内 |

| 弹簧阻尼 | 阻尼只能消耗锚点相对运动能量 | 非零阻尼全程总机械能不超过初始值并按预期衰减；阻尼 `0` 不施加任何隐式耗散 |

## 3. 数值实现约定

- 世界自身重力设为零，匀强重力场以 `F = mg` 的形式逐步施加，因此不同质量物体得到相同加速度；
- 匀强电场按 `F = qE` 累加；无电荷物体不受电场影响；
- 二维磁场按 `Fx = q·vy·Bz`、`Fy = -q·vx·Bz` 确定方向，并用精确速度旋转保持磁场不做功；
- 新建小球和物块的电荷量为 `0 C`，旧场景已有电荷值不被覆盖；所有带电物体使用 `k = 8.9875517923×10⁹ N·m²/C²` 成对计算，最小计算距离取两物体包围半径之和，新场景默认关闭物体间静电作用；
- 关闭旋转的物体使用 Rapier 转动自由度锁，并在创建和所有自定义角速度写入处显式归零；曲面摩擦把其逆转动惯量视为零，只改变平动速度；
- 绳使用 Rapier 最大长度约束；自由端杆使用包含平动质量、锚点力臂和转动惯量的双边距离约束，固定端杆使用 Rapier Fixed Joint；弹簧弹性项使用步首/步末各半次冲量的二阶速度 Verlet，轴向阻尼使用基于锚点有效质量的指数衰减冲量；
- 自由端杆每个内部子步最多执行 8 轮非线性位置 Gauss–Seidel 和 8 轮速度冲量求解；位置投影造成的离散角动量偏差在同一杆网络的约束零空间内恢复，不改变线动量或杆长；
- 弹簧的局部锚点包含角速度和转动惯量。每条弹簧以保守有效逆质量估算固有频率，整个世界统一使用满足 `ωΔt_sub ≤ 0.1` 的内部子步；默认上限为 32，超限只调整运行时有效刚度并发出警告，不修改场景数据；
- 阻尼系数 `0` 完全关闭阻尼，不设置隐藏最小值，不裁剪速度或能量；
- 每步显示的合外力由同一物理步的动量变化 `m·Δv/Δt` 得到，包含碰撞和约束的平均效果；
- 图表加速度直接使用上述合外力除以质量；动能使用 Rapier 的实际质量和有效转动惯量，不使用渲染帧差分；
- 图表按模拟时间采样，默认频率为 `60 Hz`；Worker 把多个样本批量发给主线程，因此 4× 倍速不会降低每模拟秒的样本数；
- 物体质量直接写入碰撞体，由 Rapier 根据形状和质量自动计算转动惯量；
- UI 摩擦系数先存为 `sqrt(μ)`，再使用 Rapier 的乘法合成规则，从而让接触对得到 `sqrt(μ₁ × μ₂)`；
- UI 弹性系数先存为 `sqrt(e)`，再使用 Rapier 的乘法合成规则，从而让接触对得到 `sqrt(e₁ × e₂)`；持续曲面接触资格判断使用同一公式；
- 圆弧按弦高误差自适应细分，贝塞尔曲线按控制点到弦的距离递归细分；
- 直线、解析圆弧、三次贝塞尔和连接过渡统一实现为可查询弧长、位置、切线、法线、曲率与最近点的地面路径；显示、碰撞和持续接触共用同一解析网络；
- 开启碰撞的小球由真实 Rapier 接触进入持久路径状态。活动路径碰撞对保留接触流形但关闭 Rapier 折线冲量，沿弧长推进并跨越相邻过渡；物块及其他碰撞对继续由 Rapier 求解；
- 物块使用同一解析地面网络生成的极薄双面接触带。相同材质的相邻地面和连接过渡先拼成连续链，共线内部采样点会被删除；链包围盒先排除当前步内不可能接近的地面，每个物块只让最近线段及其两侧相邻线段参与当前步求解，内部端帽则延伸到物块包围半径之外；
- 持续路径状态不依赖每帧预测接触。所需支持力为负、主动分离、走出未连接端点或偏置路径无物理解时立即脱离；重新进入必须再次满足真实接近接触；
- 路径摩擦按支持力限制接触点切向冲量，并使用刚体有效逆质量和有效转动惯量耦合平动与转动；摩擦为零时不施加耗散冲量；
- 每个地面显示实体使用独立子路径，圆弧从自身解析起点开始绘制；该显示规则不改变曲线碰撞采样，也不会创建隐藏碰撞线；
- 直线、圆弧和贝塞尔地面都先得到有序采样点。小球使用 Rapier 原生双面 `polyline`，不复制反向碰撞体；物块使用厚度仅 `0.001 m` 的双面接触带，其表面相对解析路径的偏移为 `0.0005 m`，低于既有 `0.002 m` 几何误差预算；
- `GroundJointEntity` 的 `a`、`b` 保存语义端点引用，并保留自动/手动过渡长度。两个端点可以相隔一定距离，但必须来自不同非退化地面且未被其他连接占用；
- `≤1°` 的连接失效；`1°～179°` 只接受通过有限导数、曲率、长度包络、累计转角和无自交检查的五次过渡；`≥179°` 直接使用端点间直线。旧 `directionFlipped` 数据保留但不再参与求解；
- 有效五次连接裁剪两侧地面并生成位置、切线和曲率连续的可见过渡。连接点只消除几何接缝假冲量，不会在支持力为负时把小球强制留在轨道上；
- 地面被移动或编辑后若连接不再满足条件，连接点以红色显示，物理层完全忽略其平滑交接语义；
- 所有开启碰撞的小球均可使用持续路径约束；非零摩擦由路径接触冲量处理。物块与关闭碰撞的小球不进入路径状态；
- 墙面吸附使用鼠标所控制的物体中心到折线最近点的真实欧氏距离，并以同一分离方向的物体支撑半径计算表面间隙；只按地面法向距离接近、但沿切线已远离端点的物体不进入吸附候选；
- 物理线程最多追赶 16 个固定步，设备长期跟不上时会丢弃过期追赶量并发出警告，避免界面永久卡死。

## 4. 已知边界

- 这是实时数值模拟，不是符号计算器；长时间、高刚度、极端质量比和大量高速碰撞仍会积累数值误差；
- 超出 32 个内部子步能力的弹簧会在当前模拟中使用明确告知的较低有效刚度；这是实时稳定性边界，不会静默篡改存档；
- Rapier 的一般圆弧/贝塞尔碰撞仍是误差受控的折线近似；开启碰撞的小球在确认真实接触后使用统一解析路径维持持续接触；
- 物块在曲率半径接近自身尺寸、尖锐折返或同时接触多条交叉地面时仍属于通用刚体离散接触问题；局部接触带消除连接内部端帽假冲量，但不把物块强制约束到曲线；
- 圆弧、贝塞尔、小球和控制点的渲染分段与平滑度保持现状；随缩放自适应平滑度和曲线质量设置延期，不属于本次物理修复；
- 手动地面连接没有端点距离上限，但安全五次曲线求解可能明确失败；`≥179°` 的直线退化连接优先避免绕圈，不保证与两侧地面切线连续；
- 点电荷成对计算目前为 `O(n²)`，适合教学场景中的少量电荷；大量电荷的空间加速算法留待性能数据证明有需要时实现；
- 自由端杆的非中心锚点和多重闭环使用固定 8 轮迭代；已覆盖常见不同质量、链和三角闭环，极端质量比或超大型闭环机构仍可能需要更小的固定步长；
- 同一步内同时存在强电场、强磁场和碰撞时采用固定步长分裂推进，仍有 `Δt` 量级的数值误差；
- 图表最多 8 个坐标系、每图 12 条线、全场景 32 条线和 20 个被记录物体；共享缓冲区默认按模拟时间记录 60 样本/秒并循环保留最近 300 秒。图表抽样只影响显示，公式重算和 CSV 仍使用完整记录；画布轨迹独立保留最近 1800 个渲染采样点。

任何物理核心修改都必须重新运行 `pnpm test` 和 `pnpm e2e`，并为新规律或新边界条件增加测试。
