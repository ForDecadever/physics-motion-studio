# 地面连接点端点配对与极端夹角修复设计

日期：2026-07-26  
状态：已确认，待实现

## 1. 背景与目标

当前地面连接在夹角大于约 `170°` 时会退回到“双段发卡弯”算法。该算法为了寻找有限曲率解，会主动扩大侧向绕行距离；当两端接近反向时，可能生成看起来像环绕 `360°` 的异常连接线。

当前手动工具虽然内部记录了第一次和第二次点击，但只接受间距不超过 `0.003 m` 的重合端点。因此用户无法明确选择相隔一定距离的两个端点，并让软件在它们之间生成连接线。

本次改动的目标是：

1. 彻底消除极小、极大夹角下的绕圈连接。
2. 让手动工具采用清晰的“先选端点 A，再选端点 B”流程。
3. 允许两个端点相隔一定距离，由连接实体补齐中间路径。
4. 保持普通角度连接的无自交、有限、可验证特性。
5. 不用隐藏、限幅或平滑物理图表来掩盖几何问题。

## 2. 已确认的角度规则

连接角度取第一块地面的离开切线与第二块地面的进入切线之间的较小夹角，范围为 `0°` 到 `180°`。

- `夹角 ≤ 1°`：禁止创建。
  - 提示：“两块地面的方向几乎重合，无需创建连接线。”
  - 不创建实体，也不占用端点。
- `1° < 夹角 < 179°`：尝试生成受限的五次贝塞尔平滑过渡。
- `夹角 ≥ 179°`：直接用两个所选端点之间的直线连接。
  - 不再调用五次贝塞尔或发卡弯算法。
  - 如果两个端点重合，直线长度为零，拒绝创建并提示用户调整端点位置。

精确 `180°` 的两条切线方向相反，任何非退化直线都不可能同时与两端保持切线连续。因此这一档明确优先满足“直线、无绕圈”；不承诺接缝方向连续。

## 3. 几何生成策略

### 3.1 删除发卡弯兜底

连接生成不再调用 `buildHairpinTransition`。普通平滑曲线生成失败时，连接应标记为无效并给出明确提示，不得使用更大、更绕的曲线继续兜底。

内部连接路径类别调整为：

- `quintic`：普通角度的五次贝塞尔平滑过渡；
- `linear`：`≥179°` 的端点间直线；
- `invalid`：角度、端点或曲线验证失败。

旧的 `hairpin` 路径类别不再生成。它不是场景持久化字段，因此无需升级场景格式。

### 3.2 普通角度的安全边界

`1° < 夹角 < 179°` 时继续使用五次 Hermite/贝塞尔曲线匹配两端的位置、切线和可用曲率，但候选曲线必须同时通过：

1. 所有位置、导数、切线和曲率均为有限数；
2. 一阶导数不为零；
3. 曲线没有自相交；
4. 曲率不超过现有地面路径安全上限；
5. 曲线长度和相对端点弦线的侧向偏移均在由端点间距及两侧裁剪长度决定的有限包络内；
6. 采样后不存在接近闭环的累计转角。

候选失败时，只允许缩短两侧裁剪量和控制柄后重算。重试次数必须固定且有限；全部失败后返回 `transition-invalid`，不得扩大曲线尺寸。

“有限包络”和“累计转角”的常量必须集中定义并通过单元测试锁定，避免以后再次出现隐式放大。

路径解析增加可直接用于预览和提示的失败原因：

- `angle-too-small`：夹角不大于 `1°`；
- `linear-zero-length`：直线规则下两个端点重合；
- `transition-invalid`：普通角度无法生成通过安全验证的曲线。

端点引用错误继续由现有的缺失地面、同一地面、端点占用和退化切线原因表示。

### 3.3 分离端点

手动连接不再要求两个端点重合，也不设置人为的最大世界距离。只要：

- 两端属于不同地面；
- 两端都存在且切线有效；
- 两端都未被其他连接占用；
- 坐标和距离是有限数；
- 满足角度及路径验证规则；

即可创建连接。

自动连接仍只在绘制起点进入既有端点的 `10 px` 范围时触发，避免自动跨越远距离。手动连接与自动连接共用同一套角度和几何验证规则。

## 4. 手动工具交互

1. 启用“地面连接点工具”后，所有可连接端点显示操作点。
2. 鼠标靠近 `9 px` 范围内的端点时，高亮最近的可用端点。
3. 第一次单击：
   - 记录端点 A；
   - 强调显示端点 A；
   - 提示“已选择第一个端点，请选择另一块地面的端点”。
4. 移动到端点 B：
   - 高亮端点 B；
   - 使用只存在于编辑器内存中的临时连接实时显示预览，不写入场景和撤销历史；
   - 预览无效时使用错误颜色，并显示具体原因。
5. 第二次单击：
   - 验证成功后，以一个撤销命令创建连接并选中它；
   - 验证失败时不创建实体，保留端点 A，允许继续选择其他端点。
6. 点击端点 A 本身、同一块地面的另一端或已占用端点时，不创建连接并显示原因。
7. 按 `Esc`、单击鼠标右键、切换工具或删除端点 A 所属地面时，取消待连接状态和预览。
8. 创建成功后清空端点 A，工具保持启用，可立即开始下一组连接。

连接顺序只决定预览和路径方向，不改变连接的双向可通过语义。

## 5. 数据和兼容性

- `GroundJointEntity` 仍只保存两个端点引用和现有 `transition` 设置。
- 场景继续使用 `schemaVersion: 5`，不增加迁移。
- 删除 `endpoint-gap` 作为手动连接的无效原因；加载旧场景时，分离端点连接也可恢复。
- `1° < 夹角 < 179°` 时，现有自动/手动过渡长度继续控制两侧裁剪量。
- `≥179°` 时不裁剪原地面，忽略过渡长度，直线严格连接两个原始端点。
- 删除属性栏中的“翻转方向”控件，因为它只服务于已删除的发卡弯；旧场景中的 `directionFlipped` 字段原样保留但不再参与求解，避免无必要的数据迁移。
- 属性栏在直线或无效连接上禁用过渡长度编辑，并显示当前使用的是“直线退化连接”或具体失败原因。
- 旧场景中的连接按新算法重新求解：
  - `≤1°` 变为无效；
  - `≥179°` 变为直线；
  - 其余角度只允许安全五次曲线。
- 已有材质、碰撞、图层和物理属性不变。

## 6. 渲染与物理语义

- 显示路径、碰撞采样和小球路径约束继续共用同一份 `GroundPathNetwork`。
- `quintic` 路径保持连续的端点位置与切线；通过接缝时继续携带剩余时间和切向速度，不产生额外接缝冲量。
- `linear` 路径按端点弦线生成真实可见、可碰撞的直线段。
- `≥179°` 的直线是用户确认的特殊退化规则：它不承诺与两侧地面切线连续，速度方向可以在边界发生突变，但不得生成隐藏曲线或环形路径。
- 无效连接不参与路径网络和碰撞，关联的两块地面按独立地面处理。

## 7. 测试与验收

### 7.1 几何单元测试

- `0°、0.5°、1°`：拒绝创建或解析为无效。
- `1.01°、30°、90°、150°、178.99°`：只能得到有限、无自交、导数非零的 `quintic`，或明确的 `transition-invalid`；不得得到发卡弯。
- `179°、179.5°、180°`：只能得到端点间 `linear`。
- 分离端点覆盖直线—直线、直线—圆弧、圆弧—贝塞尔和贝塞尔—贝塞尔。
- 回归样例验证路径不会接近闭环，且侧向偏移和长度不超过安全包络。
- 点击顺序反转时仍连接同一对端点，不产生占用冲突或不同的有效性结论。
- 同地面、占用端点、退化切线、重合的反向端点均给出稳定错误。

### 7.2 交互测试

- 第一次点击只选择端点，不创建连接。
- 悬停第二端点显示有效或无效预览。
- 第二次点击相隔一定距离的端点后创建连接。
- 无效第二端点不清除第一次选择。
- `Esc`、右键和切换工具可取消。
- 创建、撤销和重做均为单一原子操作。
- 不同缩放比例下，端点命中范围保持 `9 px`。

### 7.3 物理回归

- 普通角度的有效平滑连接继续满足无摩擦速度跳变 `<0.2%`、机械能漂移 `<0.5%`。
- 分离端点生成的连接具有可见碰撞路径，小球可双向通过。
- `≥179°` 直线连接不得产生环形轨迹或隐藏碰撞体；不对方向突变导致的瞬时加速度作平滑处理。
- 低速脱离、负支持力脱离、不回吸、双面碰撞和圆弧加速度回归继续通过。

- `pnpm benchmark`

所有检查通过后创建独立功能提交。

## 8. 明确不在本次范围

- 不提供用户可编辑的连接控制柄。
- 不增加新的场景版本或迁移。
- 不改变地面曲线的渲染分段质量。
- 不对图表中的真实加速度做限幅或滤波。
- 不保证 `≥179°` 直线退化连接具有切线或曲率连续性。
