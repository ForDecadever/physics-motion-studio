# ADR 0005：地面连接点与原生双面碰撞

状态：已接受
日期：2026-07-22

## 背景

相邻地面各自拥有独立碰撞体。即使两个端点在画面上重合，物理求解器仍可能在接缝处同时处理两组接触，使小球额外弹起或损失切向速度。旧版本还允许单面地面，并通过法线过滤接触；这增加了曲线背面行为和接缝交接的复杂度。

墙面吸附曾只比较物体与地面的法向距离。当最近点被夹到地面端点时，物体即使已经沿切线方向离得很远，也可能因为法向距离恰好满足阈值而被强制吸回。

## 决策

1. 应用版本升级为 `0.6.0`，场景格式升级为 `schemaVersion: 4`。
2. 新增 `GroundJointEntity`。它不复制几何坐标，而是用 `a`、`b` 保存两个语义端点引用；每个引用由 `groundId` 和 `endpoint: 'start' | 'end'` 组成，并且两端必须属于不同地面。
3. 地面连接仅在端点间距 `≤ 0.003 m`、一端离开方向与另一端进入方向的切线差 `≤ 5°`，且两个端点都未参与其他地面连接时有效。任一地面端点最多只能被一个连接引用。
4. 地面几何在创建后仍可编辑。因此连接的有效性必须按当前几何实时解析，不能只相信创建时的结果。失效连接以红色显示，物理层完全忽略它，但保留实体以便用户修正地面后自动恢复有效状态。
5. 有效连接的平滑交接只消除两个独立碰撞体在接缝处重复求解造成的额外法向冲量，并把持续接触沿连续切线交给下一块地面。第一版解析交接限定为已开启碰撞、且小球及两块地面的摩擦系数都为零的圆形物体；其他接触继续由 Rapier 普通求解。连接点不修改原始几何、不凭空补曲线，也不把超过容差的尖角伪装成平滑表面。
6. 所有直线、圆弧和贝塞尔地面统一使用各自一个 Rapier 原生双面 `polyline` 碰撞体，正反两侧都可碰撞。禁止复制反向碰撞体，也不再使用单面法线接触过滤。`3 -> 4` 迁移把旧地面的 `collisionSide` 统一写为 `both`，并把 `normalFlipped` 写为 `false`。
7. 墙面吸附以鼠标所控制的物体中心到地面最近点的真实欧氏距离为基础，再使用同一分离方向的物体支撑半径计算表面间隙。只有间隙不超过当前吸附阈值时才吸附；沿切线远离端点不能仅凭法向距离触发吸附。
8. 本次不改变圆弧、贝塞尔、小球或控制点的渲染分段。随缩放自适应平滑度和曲线质量设置继续延期。

## 影响

- 场景文件可以持久保存地面连接点；旧格式通过纯函数逐级迁移到版本 4，其他实体和已有物理属性保持不变。
- 每块地面只有一个碰撞体，双面行为由 Rapier 原生提供，避免两份重合碰撞体产生重复接触。
- 地面连接是明确、可验证的编辑语义，而不是根据空间接近程度自动猜测；端点唯一占用避免多个后继地面之间产生不确定交接。
- ADR 0002 的自适应采样误差、最大线段长度和段数上限继续有效；其中关于单面地面法线过滤的决策由本 ADR 取代。历史 ADR 文件保持原样，用于说明当时的设计背景。
