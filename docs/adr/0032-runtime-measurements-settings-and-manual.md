# ADR 0032：运行中测量、版本化设置与软件说明

- 状态：已采用
- 日期：2026-08-23
- 应用版本：`1.6.0`
- 场景格式：`schemaVersion: 20`
- 关联：ADR 0001、ADR 0003、ADR 0029、ADR 0031

## 背景

测量标注既需要随实验保存和撤销，又必须在物理运行时继续创建，不能因为画一笔或量一次距离而重新初始化 Worker。测力计还需要读取当前运行态，并把可直接计算的场力与只能从动量变化得到的接触、连接器和约束响应区分开。

用户同时需要统一管理主题、吸附和新建对象默认值。它们属于本机工作偏好，不应污染场景存档、撤销栈或当前对象。帮助菜单原有的静态快捷键列表也无法覆盖新增工具，容易与真实工具栏漂移。

## 决策

1. 记号、直尺和量角器建模为 `kind: 'measurement'`、`simulationEnabled: false` 的场景实体。记号保存最多 4096 个抽稀后的世界坐标点、颜色和米制线宽；直尺保存两点；量角器保存边点、顶点、边点。
2. 物理初始化快照在主线程剔除全部测量实体及其根引用，并以剔除后的物理内容签名决定是否重建 Worker。测量实体仍走普通文档命令、撤销、复制、保存和命中路径；运行中创建测量不会改变物理签名或模拟时间。
3. 测力计只在编辑器状态保存目标稳定刚体 ID 和局部测点。重力、电场力、磁场力、物体库仑力与外加力按同一场景公式求值；Worker 最终合力减去这些已知项，显示为明确标注的“连接器/接触/约束合力”，不伪装成可单独观测的接触分项。
4. 应用偏好使用版本化本地键保存，覆盖主题、网格、三类吸附及新建物体、地面、场、粒子源、力和记录默认值。应用时只更新编辑器偏好和后续工厂默认值，不遍历或改写当前场景。
5. 删除顶栏独立“设置”，改为“编辑 → 设置…”应用内模态窗口。非法或非有限值保留窗口并显示错误；取消不产生任何变化。
6. “帮助 → 软件说明”从工具定义注册表读取名称、图标和快捷键，人工内容只维护步骤、物理口径和边界。粒子源使用 `I`，保留 `P` 给播放/暂停，消除原有快捷键冲突。
7. `19 -> 20` 只提升格式号。旧格式没有测量实体，不需要补字段；格式 20 严格限制测量类型、折线点数、颜色、线宽和关闭模拟语义。

## 后果

- 运行中可以连续书写、测距、测角和测力，测量文档变化不会让刚体跳回初始状态。
- 可保存标注与会话探针边界明确；测力计不会把无法直接分离的求解器冲量误报成精确接触来源。
- 设置改变下一个新对象的起始条件，但已有实验仍保持可复现。
- 软件说明随工具注册表自动覆盖全部工具；详细说明仍可按产品语义人工审查。
- 场景格式在本批升级到 20，并随完整功能集合以应用版本 1.6.0 发布。
