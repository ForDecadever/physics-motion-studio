# ADR 0012：可停靠工作区、编辑草稿与关系复制

- 状态：已采用
- 日期：2026-07-29
- 应用版本：`1.1.0`
- 场景格式：`schemaVersion: 7`（不变）

## 决策

工具、图层、属性和图像面板共用轻量工作区布局管理器。面板可停靠到左、右或底边，也可在工作区内浮动、移动、从八个方向缩放、折叠、隐藏和恢复。播放栏与顶部两栏不属于可移动工作区，从结构上保证面板不会遮挡播放控制。

布局使用版本化数据 `WorkspaceLayoutV1`，只写入本地键 `motion-studio:workspace-layout:v1`，不进入场景、撤销栈或物理初始化依赖。旧的 `motion-studio:panel-sizes` 只用于迁移右栏宽度和图像高度。损坏、未知版本和窗口缩小后的越界数据通过纯几何函数修复；中央画布至少保留 `320×160 px`。

图层和实体重命名与属性输入共用待提交编辑协调器。任何选择变化、面板拖动或菜单操作发生前，合法草稿先提交为一条撤销命令，非法草稿恢复原值；这样不会把前一个对象的输入误用到后一个对象。

复制集合以用户原始选择为端点依据。两个物体都被选择时自动加入它们之间的绳、杆和弹簧；两块地面都被选择时自动加入对应地面连接点。粘贴统一生成新 ID、偏移几何并把关系重定向到副本。缺少任一端点时不复制关系，单独选择关系也不会隐式拉入端点。

图表显示数值统一由 `formatChartNumber` 格式化为最多六位有效数字，极大和极小值使用科学计数法。ECharts 使用固定绘图区边距；显示格式不改变自动数据范围、公式结果或 CSV 原始精度。

## 原因

- 应用内浮窗能提供接近专业编辑器的灵活布局，同时避免操作系统多窗口带来的同步、焦点和保存问题；
- 布局与场景分离后，同一场景在不同电脑上不会携带不合适的屏幕尺寸；
- 统一草稿协调器让重命名和数值编辑遵循相同的提交、取消和撤销规则；
- 以完整端点集合复制关系可避免副本连接到原对象或产生悬空引用；
- 固定图表边距与短数字格式能消除长小数导致的绘图区跳动，而不掩盖真实数据变化。

## 未采用方案

- 不引入第三方 IDE 停靠库：当前只需要三边停靠和单层浮窗，外部库会增加体积、嵌套布局和存档兼容负担；
- 不创建浏览器或操作系统窗口：这会增加跨窗口状态同步和 Web Worker 所有权问题；
- 不把布局写入场景或撤销栈：布局是本机工作习惯，不是物理实验内容；
- 不在缺少端点时复制连接关系：指向原对象的“半复制”关系难以理解，也容易破坏撤销和删除语义。

## 边界

首版不支持顶部停靠、标签组、任意嵌套 IDE 布局或多选共同属性编辑。隐藏面板不改变选择、物理世界或图表记录；隐藏实体仍只改变显示状态，是否参与模拟继续由 `simulationEnabled` 独立控制。
