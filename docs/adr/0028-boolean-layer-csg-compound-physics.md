# ADR 0028：可嵌套布尔图层、属性区域与复合物理

- 状态：已接受
- 应用版本：`1.5.0`
- 场景格式：`schemaVersion: 11`

## 背景

普通图层只能控制对象的视觉顺序，不能表达“两个来源共同形成一个可编辑、可碰撞、可连接的结果”。若把布尔结果烘焙为新的多边形实体，来源编辑、撤销、存档兼容和非均匀质量分布都会丢失；若渲染、命中和物理分别计算几何，又会产生画面、选择和碰撞不一致。

布尔结果还会改变引用边界：外部连接器和图表应观察一个结果对象，内部连接器则不应继续约束已经合并为同一刚体的两个来源。有限场也需要与物体相同的有序覆盖规则，但不能把无限场或不同场类型含混组合。

## 决策

1. `Layer` 是 `NormalLayer | BooleanLayer` 可辨识联合。布尔节点保存加法/减法、稳定 `resultId`、0～2 个有序输入和结果级模拟开关；派生多边形、三角网格和 Rapier 句柄不写入存档。
2. 布尔关系形成无共享的有根树。实体或子布尔节点只能属于一个父节点，禁止循环，文件深度上限为 64。物体树可混合小球与物块；场树只接受同一种有限场。地面、无限场和连接器不能成为输入。
3. 输入数组第一个元素是视觉上方来源。加法定义为“完整上方 + 未被上方覆盖的下方”，减法定义为“上方 − 下方”，因此重叠区域始终采用上方来源的密度、材质、电荷或场属性。
4. `src/scene/model/booleanGeometry.ts` 是渲染、编辑、命中和物理的唯一 CSG 解析层。它提供轮廓、孔洞、包围盒、诊断、属性区域、质量/电荷积分、凸片及共享索引碰撞网格，并按不可变场景缓存。播放中的物理世界不会重新解析 CSG。
5. 使用 `polygon-clipping@0.15.7`（MIT）执行多边形并集和差集，使用 `earcut@3.2.3`（ISC）对带孔结果三角剖分，再把相邻同属性三角形合并为凸片。两项依赖只在本地计算，不增加网络请求。
6. 圆、扇形和贝塞尔采用 `clamp(特征尺寸 × 1e-4, 1e-6 m, 5e-4 m)` 的世界误差确定性采样。单输入最多 2048 个采样顶点，单结果最多 8192 个边界顶点和 256 个凸片，全场景最多 1024 个布尔凸片；达到上限时结果明确停用，不降低精度。
7. 每个来源按原始面积得到均匀面密度和面电荷密度。保留属性区域独立积分面积、质心和极惯量，再由平行轴定理合成质量、质心和转动惯量。结果运行位置使用质心，初始角度、线速度和角速度递归继承最上方来源。
8. Float32 凸片先按摩擦和弹性材料分组，跨来源建立共享顶点、三角索引和只出现一次的外边界边，用于面积、方向、重复边、孔洞及多岛拓扑校验；同组凸片再跨来源合并为最大凸片。持续接触使用每种材料一个 `ORIENTED` 共享 `trimesh`，从求解层移除凸片内部接缝，避免水平地面上重复法线造成弹跳、增能和自发旋转。Rapier 2D 的动态凹网格开启 CCD 会冻结，因此启用结果级 CCD 时仅在单步位移达到 `0.05 m`、沿相对速度的凸形扫掠命中新障碍且双方尚无接触后，临时停用网格并创建等价最大凸片代理；已有持续接触或风险解除后删除代理并恢复共享网格。所有表示共同驱动一个刚体，并一次设置自定义总质量、质心和惯量。
   - 动态凹网格与密集曲面折线直接接触时，长端帽和质心局部选片会让大跨度、凹形结果漏掉真实接触或在片间重建流形。布尔结果因此使用同一地面路径生成的专用薄接触带：每段只按固定接缝容差短重叠，全部真实候选保留；普通矩形的局部接触带保持原实现，两类分组不叠加。
   - 小球不再同时接触布尔共享网格和边界，而只接触按材料分段的真实 CSG 边界。真实 Rapier 接触建立后，圆形来源段切换到解析持续接触；同一路径允许多个圆段，球心偏置圆使用 `1 - κ·side·radius` 换算弧长和曲率。非圆形边界段严格使用自身线段切线和零曲率，不把相邻尖角方向平滑进整段，以免平直表面产生虚假横向分力、穿入和增能；尖角切换仍由真实 Rapier 流形触发。约束位置与速度在统一的球心轨道点求解，法向及接触面摩擦按双方有效质量施加等大反向冲量和力矩；主动分离、非外力产生的离面速度或负支持力立即释放。
   - 闭合布尔轮廓的相邻表面不等于连续的球心轨道。持续接触每步比较偏置前后球心点的真实位移与沿边界可达距离；圆弧内侧接到反向外壁等尖点会产生跨实体跳变，此时立即释放并保留入射切线速度，由后续真实 Rapier 流形决定是否撞上别的表面。
   - 离轨小球首次撞入圆槽时，真实 Rapier 流形仍负责碰撞时刻与材料响应；持续状态的捕获范围按本固定步相对位移扩展，继承碰撞后的切向速度，并在零弹性条件下移除求解器残留的离面修正速度。支持力判断只比较双方场力等真实外力加速度，不能把碰撞冲量造成的槽体速度变化当成外力，否则有限质量槽体会拒绝刚建立的接触并反复撞面。
   - 有限质量圆槽已由地面支撑时，槽—球持续约束先从槽体响应中移除地面法向自由度；真实接触点同时分布在质心两侧时也移除该步的转动自由度，单点支撑仍可翻转。圆槽沿地面的水平位移与小球弧长使用质量耦合的约化拉格朗日系统和隐式中点推进，法向/切向修正通过带交叉有效质量的二元系统一次求解。这样地面反力不做功，不会先把槽压进地面再由零弹性碰撞耗能，也不使用阻尼、限速或能量裁剪。
9. 重力、电场和磁场在各质量/电荷区域质心施力并产生力矩；不同刚体的电荷区域成对计算等大反向库仑力和两侧力矩。复合电荷的磁场推进使用平动与转动三自由度隐式中点，守住磁场不做功。
10. 只有根节点创建运行刚体或场并以 `resultId` 发布 Worker、图表、轨迹和 GIF 状态。嵌套节点只贡献几何和属性；无效结果保留编辑数据，但没有碰撞、场力或运行采样。
11. 创建、嵌套、交换、移出、解散、整体变换和结果删除都使用原子可撤销命令。外部连接器与图表改绑结果；内部连接器删除；来源几何变化时锚点保持世界位置，若被切除则投影到最近有效边界。选中结果执行删除时递归删除节点、子节点和叶来源，并清理连接器、图表系列和别名；删除嵌套子结果只从存活父节点移除对应输入。复制根结果复制整棵树并重映射全部 ID，复制单独来源则产生普通独立对象。
12. 凸片提交 Rapier 前按 `Float32` 坐标规范化：拒绝非有限值，坐标量化位移不得超过世界特征容差，量化面积漂移按真实边界周长与实际位移计算的上界核对；随后去除重复与共线点并统一逆时针，规范化实际丢弃的零面积碎片误差上限仍为 `max(特征容差², 区域面积 × 1e-7)`。这样不会把大量合法 Float32 舍入的累计面积漂移误判为碎片丢失。已排序凸片使用 `convexPolyline`，Rapier 不能构造时以相同顶点三角扇精确回退，不重新降低 CSG 精度。
13. `SimulationWorld` 构造和释放具有异常安全：释放幂等，构造中途失败会回收候选资源，单个布尔碰撞结果失败只停用该结果。Worker 以事务方式清空旧引用、释放旧世界、构造候选，成功后才发布；后续来源编辑可自动重建，旧实例不得被二次释放并掩盖原始诊断。
14. 布尔来源存在移动、旋转或缩放预览时，重新解析结果的质心和角度优先于 Worker 的旧运行状态，并统一驱动填充、轮廓、选择层、质心/电荷标记及连接器。物块吸附把可见有效根布尔结果作为目标，遍历外环、孔洞和多岛边界并选择空白侧法线；普通物体与根布尔结果双向支持，隐藏、自身和来源树排除。

15. v1.5.2 将闭合钢笔物块接入同一复合几何管线。钢笔节点保存在物体局部坐标，物体位置为真实面积质心；确定性采样、面积/惯量积分、凹形凸分解、Float32 共享索引网格和真实边界接触均复用布尔实现。普通钢笔物块只使用一种均匀材料和面密度，不把派生三角形或 Rapier 句柄写入存档。
16. 布尔解析缓存先以不可变对象复用单次解析结果；差集面积为零后立即终止后续材质、分布和网格阶段。
17. v1.5.3 把跨场景缓存升级为稳定实体/节点 ID 加内容修订，并以有界 LRU 保存。整棵子树只有同一平移或旋转时，直接仿射变换轮廓、属性区域、质心、边界和世界凸片，复用局部凸片、共享碰撞网格、面积和惯量；快速路径不得调用 polygon clipping、earcut 或网格合并。缩放与来源局部修改仍执行真实 CSG。
18. 移动物体的墙面/物块吸附代理使用真实碰撞轮廓。目标空白侧法线为 `n` 时取移动轮廓朝向目标一侧的最小投影；候选提交前以双方凸片拒绝实质穿透，避免非对称预设产生错误间隙或靠近布尔体时乱跳。
19. 展开场景树后可显式选择布尔来源进行移动、旋转、缩放和节点编辑；画布默认命中仍选择根结果。父结果和后代同时选择时只变换父结果一次，父锁定递归禁止来源编辑。
20. v1.5.3 的钢笔物块圆弧接触不再把确定性采样折线直接当作持续轨道。与圆同心误差受控的三次贝塞尔段先恢复解析圆心、半径和方向；地面支撑下的槽—球约化系统以球心偏置轨道的真实弧长为广义坐标，跨越平面/圆弧曲率接缝时保持物理切向速度连续。持续轨道的空间连续性只比较同一刚体姿态下的前后路径点，刚体自身平移不能被误判为路径跳跃。
21. 离轨小球返回运动中的解析圆弧时，扫掠前点用复合刚体步前姿态、扫掠后点用步后姿态。实体侧由原始采样边界的稳定方向判断，再映射到解析法线，避免贝塞尔径向近似误差翻转空白侧；尖端前后候选法线不一致时，只有相对速度同时沿两条法线主动分离才拒绝接触。真实 Rapier 流形仍负责确认接触时刻，但无摩擦切向分量从求解前速度推进，抵消折线顶点假法线造成的水平动量误差和速度损失。
22. 不足完整一周的解析圆弧具有真实物理端点。持续状态在一个固定步内越过端点时，先把广义坐标钳制到精确端点，以端点切线和约化动量完成双方最后一次法向/切向投影，再主动释放；同一物体对在离开端点净空前不得由顶点流形立即重捕获。完整圆覆盖整条闭合路径时首尾只是采样接缝，继续循环而不触发端点释放。这样竖直切线出口满足双方水平速度一致，同时保留完整圆槽的动量与能量守恒。

## 结果

- 来源保持可编辑，结果同时是可选择、可连接、可绘图和可模拟的单一对象。
- 不同质量、材料、电荷和场强可以在同一结果中保持空间分布，不需要把属性平均到整个包围盒。
- 孔洞和多岛结果由同一几何同时驱动画面、命中与碰撞；复杂度超限或结构不完整时可修复而不丢数据。
- 相切和近相切轮廓在 Rapier 的实际 `Float32` 输入精度下仍经过面积与方向校验；失败局限于对应结果，修复来源即可恢复模拟，不需要刷新页面。
- 共享索引网格让持续接触只看到真实表面；保留凸分解仅用于高速 CCD 代理、支撑和几何查询，不是通过阻尼、限速或能量裁剪掩盖问题。
- 曲线地面与布尔真实边界分别消除了端帽密集接触和三角内部边；解析持续接触只在真实边界流形确认后激活，保持有限质量双方的动量、力矩、材料摩擦和主动离轨语义。
- CSG 重算成本集中在编辑阶段；固定步只遍历预解析凸片和属性区域。代价是复合体接触与区域力计算随凸片/区域数量增长，因此必须保留全场景上限和独立性能基准。
- 钢笔物块和曲面预设与布尔结果共享同一凹形接触实现，不会为每个三角片建立独立碰撞体；布尔整体拖动与松手也不再因场景深克隆或其他复合结果增多而重复三角剖分。
