# ADR 0008：物块地面使用连续局部接触带

## 状态

已接受，随应用版本 `0.7.0` 实施；场景格式与实体数据不变。

## 背景

连接点会裁剪两侧原地面，并在中间插入误差受控的过渡路径。小球在首次真实碰撞后使用解析路径约束，因此不会持续接受折线采样边的冲量；物块则完全依赖 Rapier 的普通刚体接触。

把原地面、过渡的两半和第二块地面分别交给折线碰撞后，连接内部存在许多短线段及碰撞体边界。物块经过这些位置时，求解器偶尔会把内部端部当作可碰撞侧边，产生与地面切线相反的假法线。无重力、无摩擦、无弹性的复现场景中，这会产生约 `357 m/s²` 的单步加速度尖峰，并把 `4 m/s` 的速率降至约 `2.42 m/s`；同一路径上的小球因解析约束而不受影响。

Rapier JavaScript 的接触过滤钩子以“碰撞体对”为粒度，不能只删除一个折线碰撞体中的某条内部接触流形。因此不能在保留原始密集折线碰撞体的同时，精确过滤单个错误端帽。

## 决策

1. 小球继续使用原有双面折线进行首次碰撞，并在确认接触后进入解析路径状态；不改变小球运动逻辑。
2. 物块使用独立碰撞组，只与由统一地面路径生成的极薄双面接触带碰撞。
3. 相同摩擦、弹性材质的相邻地面、连接过渡和后续地面合并为一条有序碰撞链；材质变化处保留边界。
4. 先删除共线内部采样点，再把每段建立为厚度 `0.001 m` 的细长碰撞带。真实开放端点保持原位；链内部端帽沿切线延伸到场景最大物块包围半径之外。
5. 先用碰撞链包围盒排除当前固定步内不可能接近的地面；每个物块在剩余长碰撞链上只启用距物块中心最近的线段及其前后相邻线段，其他可能接触的碰撞体对通过 `PhysicsHooks` 关闭求解冲量。筛选在进入 Rapier 步进前完成，钩子内部不得重新读取世界状态。
6. 加速度仍按真实的 `m·Δv/Δt` 记录，不做平滑或限幅。

## 后果

- 连接几何仍会裁剪原地面并插入过渡，但物块不再直接撞上连接内部的短线段端帽。
- 物块仍是自由刚体：可以旋转、弹起、脱离路径，并受摩擦、弹性、场和其他物体碰撞影响。
- 接触带表面相对解析路径偏移 `0.0005 m`，低于项目既有的 `0.002 m` 曲线碰撞几何误差预算。
- 物块场景需要额外的静态碰撞带和每步局部线段选择，因此必须保留含多组连接地面和多个物块的性能基准。
- 极端大物块、很小的曲率半径或同时接触多条交叉地面仍可能需要更完整的多点曲面接触算法；本决策不把物块改造成沿路径运动的导轨物体。
