# ADR 0023：碰撞绳多段接触流形与批量约束求解

- 状态：已采用
- 日期：2026-08-09
- 应用版本：`1.3.5`
- 场景格式：`schemaVersion: 10`（不变）
- 取代：ADR 0021 中拉紧绳的有限接触波质量分配
- 细化：ADR 0022 的碰撞绳速度约束顺序

## 背景

旧实现为每个“绳 ID + 物体 ID”只保留最早命中的一条绳段。摆绳扫过圆球时，其余实际接触段被丢弃，绳只能以近似直线与圆球相交，视觉和物理都像刚杆。每个接触还会重复执行整绳位置与速度扫描，局部冲量随后被节点速度重建覆盖，造成明显卡顿。

## 决策

1. 每条实际接触绳段拥有独立的运行时流形记录，保存段、物体、接触法线、中心线接触点、首次接触时间及本子步累计法向/摩擦冲量。
2. 只有相邻段的接触点距离小于 `0.002 m` 且法线点积不低于 `0.98` 时才视为同一个共享顶点接触；沿圆周方向不同的接触必须保留。接触间隙超过 `0.004 m` 后释放，避免贴面滑动时频繁重建。
3. 位置阶段按绳分组：先把全部接触段及物体推出，再统一扫描逐段上限、双向长距离上限和整绳弧长。内部节点极轻时，整绳弧长误差优先通过真实端点消化，使局部弯曲与张力传递可以同时成立。
4. 所有位置约束完成后只重建一次节点速度。法向、摩擦、逐段和长距离速度约束再按组求解；持续接触不重复施加材料弹性。
5. 新接触且材料弹性非零时，瞬时弹性部分使用整条约束的端点有效质量，避免把有限冲量全部交给一个极轻节点；位置修正、非弹性法向响应和摩擦仍作用于真实接触段，因此持续贴面时不会恢复成刚杆。
6. 碰撞候选使用“整绳扫掠包围盒—物体候选—局部绳段包围盒”两级筛选。流形、物体候选和活动接触数组跨固定步复用；持续接触优先做当前解析距离检查，只有新接触才执行连续扫掠细化。

## 后果

- 地面锚定摆绳可以沿第三方圆球形成多个相邻接触段并绕到另一侧，同时保持绳长上限、有限速度和真实动量传递。
- 圆形物体继续使用解析胶囊距离，旋转物块继续使用 Rapier 形状查询；直接端点物体仍排除碰撞。
- 场景字段、迁移、Worker 消息、运行节点数量、画布和 GIF 接口均不改变。
- 8 组同时绕行成为实时容量基准；20 根连接器完全同步接触地面和第三方物体继续作为记录性极端场景，不通过减少碰撞段或放宽误差来优化。
