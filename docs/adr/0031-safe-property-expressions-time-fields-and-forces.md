# ADR 0031：安全属性表达式、时变场与外加力

- 状态：已采用
- 日期：2026-08-23
- 应用版本：`1.6.0`
- 场景格式：`schemaVersion: 19`
- 关联：ADR 0001、ADR 0003、ADR 0011、ADR 0029

## 背景

普通数值属性此前只能保存立即生效的数字，场强也只能是常量。用户需要定义全局符号，把同一个参数复用于物体、地面、粒子源和布尔结果，并让场强及外加力随模拟时间变化。直接执行字符串脚本会破坏存档安全、可复现性和数值边界；只把计算结果写回属性又会丢失公式关系。

外加力还必须保存目标的稳定引用和局部锚点，才能在刚体移动、旋转、复制及布尔组合后继续作用于同一物理位置。

## 决策

1. 新增独立的安全标量解析器。它只接受数字、ASCII 标识符、括号、`+ - * / ^`、隐式乘法以及 `abs/sqrt/sin/cos/tan/min/max`；不调用 `eval`、`Function`，不接受属性访问、赋值或脚本字符。
2. 解析器限制 256 个字符、128 个语法树节点、32 层深度和绝对值不超过 8 的常数指数。除零、无效开方或其他非有限结果返回空值，不能传播 `NaN`。
3. 全局变量按列表顺序解析，只能引用排在前面的变量；`t`、`pi`、`e` 和函数名为保留字。静态属性绑定保存安全目标、原公式及最近有限回退值；修改变量时用一条原子命令重新计算全部绑定。
4. 普通属性公式不允许 `t`。重力/电场的标量大小、磁场 `Bz`、外加力大小和方向允许 `t`，并在每个逻辑固定步的起点求值。运行时结果无效时只跳过该场或力，并按实体和属性去重警告。
5. 外加力保存目标普通/根布尔刚体 ID、目标局部锚点、大小和世界方向。物理层使用 Rapier 的点力接口，因此偏心力自然产生转矩；锁定旋转的刚体只响应平动分量。
6. 布尔组合和解散按变换前后的世界锚点重算局部锚点；复制时把力目标映射到副本，删除目标时级联删除力。运行时禁止创建和编辑力实体。
7. `18 -> 19` 迁移只增加空的 `globalVariables` 与 `propertyExpressions`。旧场、物体和连接器数值保持不变；打开格式 19 时重新解析变量和属性绑定，不信任存档中的过时派生值。

## 后果

- `a=10`、质量 `3a`、磁场 `a/10` 等关系可以保存、撤销并在变量变化后原子更新。
- 时变场与力沿用物理 Worker 的固定时间线，暂停不会推进公式时间，重置后从 `t=0` 重算。
- 公式求值不执行任意 JavaScript；非法输入在编辑或打开文件时被拒绝，运行时奇点不会污染物理状态。
- 场景格式在本批升级到 19，并随完整功能集合以应用版本 1.6.0 发布。
