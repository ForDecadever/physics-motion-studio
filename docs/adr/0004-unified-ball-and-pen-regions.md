# ADR 0004：统一小球与钢笔范围

状态：已接受  
日期：2026-07-22

## 背景

质点、小球和点电荷在编辑器中的大部分属性重复，却使用了不同预设和形状结构；多边形场也无法表达钢笔工具的平滑控制。继续为这些重复类型分别增加属性，会让物理分支、属性面板和存档格式越来越难维护。

## 决策

1. 物体工具只保留“小球”和“物块”。小球统一拥有质量、电荷、半径和碰撞开关；关闭碰撞时不创建 Rapier 碰撞体，但仍参与场力与可选的物体间静电作用。
2. 小球用红色/蓝色分别表示碰撞开启/关闭；电荷为正或负时使用独立的 `+` / `−` 标记，电荷为 `0` 时不显示标记，避免同一种颜色表达两个物理含义。
3. 场景格式升级到版本 3。旧质点和点电荷迁移为小球；旧圆形场补充完整圆的起始角与圆心角；未知字段继续保留。
4. 新建小球和物块的电荷量均为 `0 C`，新场景默认关闭物体间静电作用；用户显式设置非零电荷并开启物体间静电作用后，仍按库仑定律计算。旧场景中的已有电荷值原样保留。
5. 自由场范围使用闭合三次贝塞尔路径。节点自动获得平滑入/出控制柄，拖动一侧时镜像另一侧；物理范围判断对曲线采样后使用点在闭合边界内判定。
6. 旧多边形场继续只读兼容和编辑兼容，但工具栏不再创建新的多边形场。
7. 每个地面实体在显示层建立独立子路径，圆弧先移动到自身解析起点再绘制；显示路径与碰撞采样保持独立，避免不同地面之间出现只有显示、没有碰撞的假连线。
8. 无摩擦圆弧的解析约束只由真实求解接触激活和延续。接触须距解析圆周不超过 `0.003 m`；径向分离速度超过 `0.001 m/s`、所需支持力为负或越过圆弧端点时立即脱离，预测接触不得把已离轨小球重新吸回。
9. 本次不调整圆弧、贝塞尔、小球或控制点的渲染分段；随缩放自适应平滑度和曲线质量设置延期设计。

## 影响

- 创建工具、画布命中、渲染、物理碰撞、图表颜色和属性面板共享同一套小球语义。
- 保存的新场景需要版本 3；旧版本由纯函数逐级迁移，不原地修改输入。
- `chargeC` 类型和场景版本保持不变；默认值修正不覆盖旧存档中的已有电荷。
- 贝塞尔场边界是误差受控思路下的采样近似，不是符号曲线求交；后续若开放极端尺度，应把采样误差改成场景级精度参数。
