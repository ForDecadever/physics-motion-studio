# ADR 0021：自由端弹簧首步切换与拉紧绳局部碰撞

- 状态：已采用
- 日期：2026-08-09
- 应用版本：`1.3.3`
- 场景格式：`schemaVersion: 10`（不变）
- 细化：ADR 0020 的自由端运行初始化和拉紧绳接触分配

## 背景

自由端弹簧在物理世界建立时直接把运行几何规范到原长，导致用户尚未点击播放就看到端点移动。另一方面，预压弹簧虽然保存了势能，但无接触时没有在首步向原长展开；挡板前存在物体时也不能稳定地把储能传给物体。

碰撞绳接近拉直时把位置和速度响应全部切换到总端点，虽然能够传递反作用，却会抹掉碰撞点的局部自由度，使端点可移动的绳仍表现成杆。简单把全部冲量交给极轻的局部节点又会让节点获得非物理的巨大速度，并破坏系统动量分配。

## 决策

1. 自由端弹簧运行记录同时保存场景编辑长度、运行原长和“模拟是否已经开始”。物理世界刚建立以及重置后，运行折线严格使用场景端点，不提前改形。
2. 首个物理子步开始时才切换到运行坐标：编辑长度大于原长时回拉到无载原长；编辑长度小于原长时保留对应的初始压缩量并向原长展开。若挡板前有物体或地面，连续接触约束限制端帽位置，弹簧半冲量把储能传给接触物体和动态锚点。
3. 拉紧绳只在“两端固定且端点距离等于最大绳长”时使用唯一合法的直线投影。至少一端可移动时，接触位置修正始终作用于碰撞段相邻节点，使局部形状能够离开端点弦线。
4. 拉紧绳的法向和摩擦冲量分成两部分：大部分按总端点有效质量传递张力，小部分用于接触段的有限质量横向波。局部参与质量由绳质量和当前段占整绳比例限定，避免把全部冲量交给单个极轻节点。
5. 逐段长度采用过松弛 Gauss–Seidel，并与双向长距离上限、整绳弧长和速度投影交替执行。每段和总弧长仍使用原有容差；过松弛只加快约束收敛，不增加隐藏弹性、阻尼或允许长度。

## 后果

- 修改原长后，停止画面和存档坐标保持不变；只有播放后的运行几何发生释放或回拉。
- 预压自由端弹簧可在首步开始展开，并把挡板前的小球或物块顶出；伸长自由端不会在停止状态提前缩短。
- 拉紧但端点可移动的碰撞绳能够形成可测量的局部曲率，端点同时靠近以满足不可伸长条件；双固定端满长度绳仍保持数学上唯一的直线构型。
- 场景字段、迁移、Worker 消息和 GIF 运行折线接口均不改变。
