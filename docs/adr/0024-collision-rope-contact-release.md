# ADR 0024：碰撞绳活动接触与邻近流形分离

- 状态：已采用
- 日期：2026-08-09
- 应用版本：`1.3.6`
- 场景格式：`schemaVersion: 10`（不变）
- 修正：ADR 0023 的持续接触释放语义

## 背景

ADR 0023 引入了按绳段保存的持续接触流形。旧实现使用同一个 `timeRatio` 同时表示“本步真实扫掠撞击”和“步首或步末已处于邻近范围”，导致微小数值重叠但已沿法向分离的绳段仍进入活动位置与绳长约束。即使法向冲量已经为零，整绳仍会保持接触态投影，视觉上表现为绳粘在球面。

## 决策

1. 接触候选明确记录是否由本步跨越碰撞面的连续扫掠建立；真实扫掠撞击始终求解，避免高速穿模。
2. 流形缓存和活动单边接触使用不同生命周期：邻近记录可以继续缓存，但只有正在接近、静止接触或存在有效穿透的记录才进入位置、速度和接触态绳长求解。
3. 未发生真实扫掠、穿透不超过 `1e-5 m` 且法向分离速度超过 `1e-4 m/s` 时，接触立即退出活动求解；缓存仍可保留到间隙超过 `0.004 m`，供再次接近时快速更新。
4. 该释放不施加拉力、反向冲量或隐藏阻尼；材料摩擦只在存在有效法向冲量时工作。

## 后果

- 绳段碰撞后可以按真实分离速度离开球面，不会因为邻近缓存继续切换到接触态绳长投影。
- 持续承受支持力的多段绕球接触仍然保留；高速扫掠、穿透修正和首次材料弹性不受影响。
- 运行时仅增加一个接触来源标记，不改变场景、Worker 消息、渲染节点或 GIF 数据。
