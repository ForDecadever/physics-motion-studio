# ADR 0026：碰撞绳使用统一 XPBD 接触求解器

- 状态：已采用
- 应用版本：`1.4.0`
- 场景格式：`schemaVersion: 10`（不变）
- 取代：ADR 0023～0025 中分离的接触位置、端点速度和绳长补丁顺序

## 背景

旧实现先求绳长，再单独投影绳—物体和绳—地面接触，随后重建内部节点速度，并额外执行端点专用的整绳速度投影。各步骤使用的自由度集合不同，局部绕行节点的位移可能被重复换算为端点冲量，表现为球面粘滞、端点沿绳增能、单摆抽搐或绳退化为杆。

## 决定

1. 碰撞绳使用独立 `RopeXpbdSolver` 协调每个内部物理步；Rapier继续负责刚体预测、普通碰撞和形状查询。
2. 每轮依次求解实际绳段接触、逐段最大长度、双向长距离上限和整绳弧长，并交替扫描方向。接触与长度共享同一批位置迭代，不再在接触后调用端点专用的整绳补丁。
3. 所有位置约束完成后执行一次最终不可伸长收敛并只重建一次内部节点速度；之后执行一次接触法向、库仑摩擦及拉伸速度投影。
4. 接触位置、持续法向和摩擦作用于真实相邻节点。理想不可伸长绳的新生弹性撞击使用整条约束的有效质量，避免极小节点质量使完全弹性物体直接穿过绳；该整体验证只用于首次弹性冲量，不用于持续接触或摩擦。
5. 持续流形继续按绳段和障碍物保存。相邻接触只有在位置与法线都接近时才合并；超过释放间隙且正在分离时退出活动约束。
6. 按最大相对扫掠距离与 `max(2 × radiusM, linkLength)` 的比值选择 `1～8` 个约束子步。高速接触仍使用连续扫掠，不限速、不增加隐藏阻尼或能量边界。
7. 没有物体或地面接触的碰撞绳使用同一不可伸长数学约束的快速路径，避免为无接触场景支付接触流形迭代成本。

## 结果

- 绳可以沿圆球形成多段包络，接触结束后能释放，不会把内部弯曲速度持续注入端点。
- 绳长、接触和速度重建的顺序只有一个权威入口，后续修复不得重新添加独立的端点接触补丁。
- 运行折线、GIF、命中检测、Worker消息和存档字段均不变。

## 后续补充

ADR 0027 修正了本决策第 3 项：最终不可伸长收敛仍属于统一批次，但其后必须重新扫掠实际移动的绳段并执行接触投影，不能以脱离接触的纯绳长投影结束。
