# ADR 0018：不可伸长碰撞绳与零质量弹簧端帽

- 状态：已采用；自由端几何与绳长求解细节由 ADR 0019 取代
- 日期：2026-08-09
- 应用版本：`1.3.0`
- 场景格式：`schemaVersion: 10`
- 取代：ADR 0017 中零质量碰撞绳、带质量弹簧和动态自由端质量点模型

## 背景

零质量碰撞绳没有可用于弯曲和接触投影的惯性节点；当改用很小质量时，逐段约束容差又会沿长链累计，表现为端点把绳持续拉长。带质量分段弹簧同时增加节点数、局部刚度和全局子步需求，既不适合实时编辑器，也与“自由端弹簧像可储能墙面一样反弹物体”的产品语义不一致。

## 决策

1. 绳关闭碰撞时质量固定为 `0 kg`，继续使用理想最大长度关节。开启碰撞时质量自动补足到至少 `0.001 kg`，并使用动态柔性节点；不再存在“零质量但开启碰撞”的绳。
2. 每个子步交替求解逐段最大长度、整绳总弧长、连续胶囊接触和再次长度投影。位置与速度使用同一约束梯度和有效质量；最终投影所有继续增大弧长的相对速度。长度误差与绳质量无关，目标为 `max(1e-4 m, maxLength × 1e-4)`。
3. 弹簧数据继续保留 `massKg` 与 `collisionEnabled` 以兼容统一实体接口，但格式 10 强制两者分别为 `0` 和 `false`，属性栏只显示只读摘要。
4. 双端都连接的弹簧保持原有速度 Verlet、真实零阻尼和自动子步，不改变旧场景的长期能量语义。
5. 单自由端弹簧保存相对动态锚点的局部轴向，以一个压缩坐标 `c` 描述端帽位置和势能。它只在物体从外侧轴向接近时排斥，并把等大反向冲量和力矩施加给动态锚点。
6. 双自由端弹簧保存固定中点和世界轴向，两端共享同一个压缩坐标并围绕中点对称移动，避免两侧接触重复计算势能。
7. 自由端帽使用真实小球或旋转矩形支撑半径，并按子步接触更新压缩量。侧向掠过不触发；压缩到原长时使用无摩擦、零弹性硬停止防止穿过基部。
8. `v9 -> v10` 把碰撞绳质量补足到最低值、非碰撞绳归零，并把所有弹簧归零质量、关闭普通碰撞；端点、原长、刚度、阻尼、半径和材料原样保留。
9. 柔性碰撞段只由自定义连续扫掠求解，不再同时创建不会参与 Rapier 冲量求解的运动学胶囊。绳长求解复用每条绳的工作区；平行线段最近点使用无分配的标量退化分支，避免密集贴地场景出现垃圾回收尖峰。

## 后果

- 极小质量碰撞绳不再依靠增大质量掩盖伸长，长绳和高速外拉使用同一误差口径。
- 自由端弹簧不受重力或普通地面碰撞影响，而是成为计算量固定的轴向储能端帽；一个动态锚点可携带端帽平移和旋转。
- 弹簧不再提供任意方向的柔性软体或普通碰撞能力；如未来需要完整可变形弹簧，应作为另一种实体和新的能量一致积分模型实现。
- 场景格式升级，因为原有非零质量或普通碰撞弹簧会被有意规范为新语义。
- 自定义碰撞段成为柔性绳的唯一碰撞响应来源，避免同一几何同时承担无效的 Rapier 宽相位开销。

## 依据

- 绳的整体弧长约束与逐段约束使用相同 PBD 拉格朗日梯度，避免两套位置修正互相打架。
- 弹簧端帽继续采用 ADR 0009 的对称半冲量和 `ωΔt_sub ≤ 0.1` 稳定性条件，不使用隐藏阻尼、速度限制或能量边界。
