# ADR 0025：碰撞绳端点速度投影使用一致自由度

- 状态：已采用
- 日期：2026-08-09
- 应用版本：`1.3.7`
- 场景格式：`schemaVersion: 10`（不变）
- 修正：ADR 0023 的接触态整绳速度投影

## 背景

碰撞绳绕过圆球后，内部柔性节点会因接触位置投影和曲率变化产生真实的局部速度。接触批次还会执行一次只允许真实端点响应的整绳速度投影，以便把拉紧约束传递给端点物体。

旧实现从有效逆质量中排除了内部柔性节点，也不会把最终冲量施加给这些节点；但约束速度 `Cdot` 仍累计了所有内部节点的速度。这样得到的冲量分子和分母对应不同自由度，内部节点的绕行速度会被集中施加到端点小球。持续接触时该错误可重复发生，表现为端点沿绳方向增速并试图穿过障碍物。

## 决策

1. 端点专用整绳投影只使用实际参与该次冲量分配的端点自由度计算 `Cdot` 和有效逆质量。
2. 内部柔性节点同时从该次 `Cdot`、有效质量和冲量分配中排除，三者必须使用一致的自由度集合。
3. 内部节点仍由局部接触、逐段速度、双向长距离速度和完整整绳速度投影求解；本决策不删除其真实质量、动量或绕行运动。
4. 不增加阻尼、速度限制或能量裁剪；材料合成、持续接触流形、绳长容差和 Worker 接口均保持不变。

## 后果

- 绳节点因绕球改变方向时，不会再把自身速度错误注入端点物体。
- 真实端点伸长速度仍由端点专用约束消除，绳长和张力传递语义保持不变。
- 场景字段、迁移、渲染折线、GIF 数据和用户属性均无需修改。

## 验证

- 构造总弧长达到上限的弯曲绳，让内部节点具有伸长方向速度、端点保持静止；执行端点专用投影后端点速度必须低于 `1e-9 m/s`。
- 无摩擦、无外力的绕球摆绳运行 6 秒，端点最大速率不得超过初始值 `2%`，并且端点与大质量圆球的残余穿透不超过 `0.002 m`。
