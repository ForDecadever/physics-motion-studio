# ADR 0030：传送带、双自由端弹簧质量响应与磁聚焦精度

- 状态：已采用
- 日期：2026-08-23
- 应用版本：`1.6.0`
- 场景格式：`schemaVersion: 18`
- 细化：ADR 0003、ADR 0009、ADR 0018、ADR 0021

## 背景

双自由端预压弹簧原来始终围绕固定中点展开。当轻、重两个物体分别接触两侧时，轻物体先离开固定挡板，剩余一侧又获得翻倍力，导致重物体被额外补速，质量响应失真。

粒子源在磁场中只解析旋转速度，位置仍按步末速度作直线推进；有限场进出还按整步起点判断。这两项误差会让等回旋半径的圆形磁场聚焦产生可见偏差。

普通地面此前只有静止表面摩擦，无法表达传送带的目标切向速度。

## 决策

1. 双自由端弹簧在两侧同时接触时，以真实接触面重建运行中点和当前长度。每个挡板的总力始终为 `k·c + d·dc/dt`；同一挡板有多个接触时只在该挡板内平分，不能因另一侧离开而翻倍。
2. 质量为零且两端自由的弹簧只有两侧同时接触时才向外传递成对冲量，避免单侧凭空获得外部动量。停止态端点和首步切换语义保持不变。
3. 离子在常量 `Bz` 内使用解析速度旋转及其时间积分得到的圆弧位移。只有预测到一个固定步内磁场定义发生变化时，才把该步拆为 16 个粒子边界子步；普通无边界轨迹仍执行一次解析推进。
4. 地面保存 `enabled`、`direction` 和非负 `speedMps`。正向定义为几何起点到终点；连接过渡按相邻地面端点方向换算。
5. 小球持续路径接触以“接触点速度减表面速度”计算库仑摩擦。物块和复合刚体的传送带地面碰撞体关闭 Rapier 自带切向摩擦，再用真实法向接触冲量作为摩擦上限，向接触点施加目标表面速度冲量，避免重复计算摩擦。
6. `17 -> 18` 迁移只为旧地面补 `{ enabled: false, direction: 'forward', speedMps: 1 }`，旧场景物理行为不变。

## 后果

- 不同质量物体接触同一预压弹簧时获得相同力、不同加速度，并守住总动量。
- 磁场不做功的同时，粒子轨迹和有限场出口都使用一致的圆弧几何；边界精度成本只发生在跨界步。
- 传送带依赖真实摩擦；摩擦为零时不施加拖动冲量。物块、小球和复合刚体共用相同表面速度语义。
- 场景格式在本批升级到 18，并随完整功能集合以应用版本 1.6.0 发布。
