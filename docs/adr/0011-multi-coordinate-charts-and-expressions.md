# ADR 0011：多坐标系图像区、安全公式与共享记录

- 状态：已采用
- 日期：2026-07-29

## 决策

图像区使用可滚动的响应式卡片布局。场景最多保存 8 个坐标系，每个坐标系独立保存名称、横纵轴定义、跨物体别名绑定和曲线样式；每图最多 12 条线，全场景最多 32 条线、20 个被记录物体。新场景和从 v6 升级的旧场景默认包含一张空白 `t-y` 坐标系。

坐标轴既可选择预设物理量，也可使用受限表达式。表达式由自定义 tokenizer、递归下降解析器和语法树求值器处理，不调用 `eval`、`Function` 或动态 JavaScript。解析器限制输入长度、节点数、嵌套深度和指数范围，并对加减、函数参数及单位常量执行严格量纲检查。裸变量指当前曲线物体；`@A.x` 通过别名绑定到稳定实体 ID，物体重命名不会破坏公式。

所有坐标系共享一个紧凑的定长采样缓冲区。每个被记录物体只保存一次完整状态，默认按模拟时间 `60 Hz` 保留最近 `300 s`；图表显示按宽度抽样并约以 `15 Hz` 刷新，完整记录仍用于公式重算和 CSV。后来加入的物体只从加入时刻开始有数据，除零、缺失对象或非有限结果形成断点而不影响物理模拟。

图表配置属于 `SceneDocument`，纳入撤销、重做、未保存提示和 `schemaVersion: 7` 存档；运行采样属于临时运行状态，不写入场景文件。图表配置变化不能重建物理世界或清空已有记录。

单图导出宽表 CSV，全部坐标系导出长表 CSV。每条线独立保存显示状态、十六进制颜色、实线/虚线/点线和 `1～6 px` 粗细；同一物体跨图默认使用稳定颜色，同图批量添加时避免默认颜色重复。

## 原因

- 多坐标系能在同一实验中比较不同变量关系，而不局限于“物理量随时间”；
- 共享原始状态可让修改公式后立即重算历史，同时避免同一物体在多张图中重复记录；
- 严格量纲能在提交前指出 `m` 与 `m²` 不能相加等物理错误；
- 稳定实体 ID 与易读别名兼顾存档可靠性和公式可读性；
- 配置与采样分离能保持场景文件小而可读，并避免仅改颜色就重置实验。

## 未采用方案

- 不执行用户输入的 JavaScript：难以限制副作用，也不能可靠进行量纲检查；
- 不为每条曲线单独记录数值：多图引用同一物体时会浪费内存，也不利于换轴后重算；
- 不把采样写入场景：默认 300 秒完整状态会让文件迅速膨胀，运行记录应通过 CSV 明确导出；
- 不在首版加入条件、比较、分段函数、对数轴、双纵轴或 3D 图表：这些能力需要额外的单位与交互约定。

## 边界

一张坐标系只有一套横轴和纵轴公式，应用于其中所有物体。记录达到容量后循环覆盖最旧样本；若实验需要永久保存完整数据，应在需要的时刻导出 CSV。图表的显示抽样只影响绘制，不改变公式重算和导出数据。
