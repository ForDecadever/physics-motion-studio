# ADR 0019：独立弹簧几何与拉直绳投影

- 状态：已采用；伸长自由端运行态与局部绳接触细节由 ADR 0020 取代
- 日期：2026-08-09
- 应用版本：`1.3.1`
- 场景格式：`schemaVersion: 10`（不变）
- 取代：ADR 0018 中自由端始终按原长定位、属性栏只读摘要，以及碰撞绳只依靠整绳投影的细节

## 背景

自由端弹簧原先以原长直接生成运行几何，修改原长会让画布长度跳变；端帽半径同时加入轴向间隙又没有对应可见轮廓，导致物体在视觉接触前反弹。碰撞绳只使用全绳弧长梯度，拉直时内部节点梯度接近零，过松弛修正会把微小误差放大成规则锯齿。

## 决策

1. 空白画布创建弹簧自由端；世界固定点只通过显式操作建立。解除、拖动和坐标编辑保留实际端点位置，原长不再改写几何。
2. 自由端运行记录分别保存初始几何长度与向内行程。短于原长表示单向预压，长于原长表示无拉力松弛；无接触时端帽停留在编辑位置。
3. 自由端显示横向挡板。`radiusM` 是挡板半宽，只参与横向覆盖；轴向接触面位于可见挡板中心线。
4. 弹簧通用质量、普通碰撞和材料字段继续保留以兼容格式 10，但属性栏不显示这些无效选项。
5. 碰撞绳使用逐段最大长度、从两端按绳上距离建立的长距离上限和整绳弧长三层不等式。移除 `1.8` 倍位置过松弛；位置求解完成后重建节点速度并投影拉伸速度。
6. 当端点距离达到最大绳长时，绳只有唯一的直线构型，内部节点按弧长比例直接投影到端点连线，避免长链迭代传播造成锯齿和卡顿。
7. 两个固定端点距离大于最大绳长属于无解输入；编辑器拒绝新修改，旧场景在运行时警告并按固定端点距离拉直，不改写存档。
8. 绳的位置与速度投影复用预分配数组，逐段约束和整绳弧长约束在同一批次内求解，内部质量节点每批只写回一次。圆形物体与连接器胶囊使用解析距离，直线地面内部区域使用解析扫掠；曲线、旋转物块和地面端点仍使用通用连续碰撞。CCD 细分后的二分次数按 `0.002 m` 接触容差设置为 4 次，最坏细化误差仍小于该容差。

## 后果

- 当前长度和原长可以独立编辑，自由端预压与松弛具有明确的一侧碰撞语义。
- 端帽的显示、主画布物理接触和 GIF 使用同一几何，不再存在不可见轴向半径。
- 极小质量长绳不再依赖全局过松弛传播张力；完全拉直场景的成本从多轮长链迭代降为一次线性投影。
- 本次没有增加场景字段，旧端点、材料和世界固定点全部保持兼容。
- 完全同步的 20 根碰撞连接器压力场景在当前 Windows 环境中稳定耗时低于固定步预算，但仍存在约 16 ms 的周期性 P99 尾部；性能基线保留该未达标结果，后续不得通过减少物理断言或删除样本掩盖。
