# ADR 0020：碰撞绳局部接触与弹簧地面端帽

- 状态：已采用；弹簧首步切换与拉紧绳碰撞响应由 ADR 0021 细化
- 日期：2026-08-09
- 应用版本：`1.3.2`
- 场景格式：`schemaVersion: 10`（不变）
- 取代：ADR 0019 中“伸长自由端运行时停在编辑位置”的决定，并细化其碰撞绳接触分配

## 背景

碰撞绳连接地面时，首段与自身锚点地面的自然重叠会被当成普通碰撞，导致单摆经过最低点时被错误制动。物体撞击有松弛量的绳时，若把冲量直接传给整绳两个总端点，内部节点就没有局部弯曲自由度，绳会表现得像杆。自由端弹簧还缺少与地面的可见挡板接触，且编辑长度大于原长时没有在运行开始恢复到无拉力原长。

## 决策

1. 绳端连接普通地面或地面连接段时，只忽略首段或末段在自身锚点半径内与该路径的局部重叠。绳的其他位置继续与同一路径碰撞。
2. 松弛碰撞绳把物体接触的位置修正、法向冲量和摩擦冲量分配到接触段相邻节点；绳接近拉直后改由整绳端点承受反作用。接触后依次投影逐段长度、双向长距离张力、整绳弧长和拉伸速度。
3. 伸长的单自由端弹簧在物理世界初始化时，以已连接端为基准把运行态挡板归到原长；双自由端围绕原中点对称归位。短于原长的预压位置保持不变。上述归位不写回场景、存档或撤销历史。
4. 自由端挡板与直线、圆弧、贝塞尔和地面连接过渡使用同一标准双面路径进行连续接触。挡板宽度有限，`radiusM` 只决定横向覆盖；地面接触只改变轴向压缩量，不叠加材料恢复冲量。
5. 动态锚点承受地面挡板反作用和偏心力矩；与自身地面锚点重合的局部接触按与绳相同的范围排除。

## 后果

- 地面锚定的碰撞绳单摆不会在最低点因锚点自碰撞停下，绳身仍能绕回并碰撞同一地面。
- 有松弛量的绳在小球或物块撞击处形成局部弯曲；完全拉直时仍只有唯一的直线合法构型。
- 自由端弹簧的停止态几何和原长仍可独立编辑，但运行态从无拉力原长开始；预压仍可储能并发射物体。
- 弹簧地面反弹只来自弹簧势能和阻尼，不使用额外材料弹性，因此不会重复增能。
- 没有增加场景字段或 Worker 消息，格式 10 存档保持兼容。
