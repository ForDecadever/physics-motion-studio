# ADR 0016：紧凑地面接缝与连接器—地面碰撞

- 状态：已采用；零质量碰撞绳的单直段代理由 ADR 0017 取代
- 日期：2026-08-02
- 应用版本：`1.1.1`
- 场景格式：`schemaVersion: 8`
- 取代：ADR 0015 第 7 项中的非对称自动过渡搜索

## 背景

非对称候选搜索会把自动地面过渡扩大到旧算法的数倍，并在创建和编辑时反复计算大量曲线。另一方面，端点重合且行进切线连续的直线—圆弧若没有路径邻接关系，小球会先离开解析路径，再被离散碰撞体重新捕获，高速时表现为折线。无质量连接器原本只检查物理步末的中心线采样，也可能漏过子步内穿越的地面。

## 决策

1. 自动过渡恢复紧凑的对称裁剪公式，并按固定缩放序列选取首个安全五次曲线；保留曲率自适应子步、精确边界时间和可达路径碰撞屏蔽。
2. 重合反向端点以及重合且行进切线连续的直线—曲线/曲线—曲线使用 `direct` 无形接缝。它只连接路径网络，不增加曲线、裁剪或碰撞片段；共线直线—直线仍保持旧的无需连接语义。
3. 新建连接器点击小球或物块时使用局部中心锚点 `(0, 0)`；后续拖动、旧存档和复制粘贴仍保留实际锚点。
4. 无质量连接器保存每个内部子步前后的代理段位置，使用扫掠包围盒筛选地面，并沿时间和线段参数细化首次胶囊接触。冲量按全连接器弧段比例传回端点；其中碰撞绳的内部形状与多段代理由 ADR 0017 细化。
5. 有质量连接器继续使用 Rapier 动态胶囊或节点；所有连接器只与标准双面折线路径碰撞，不加入物块专用薄条碰撞组，以免重复冲量。

## 后果

- 自动连接恢复紧凑尺寸和低编辑开销，同时高速小球可跨越有效过渡及无形接缝。
- `direct` 是运行时解析结果，不新增存档字段，旧格式 8 场景无需迁移。
- 两端均固定的无质量连接器与固定地面重叠时双方都没有可运动自由度，因此不会产生位置修正。
- 扫掠接触比单帧采样计算量更高，但只对开启碰撞且包围盒接近地面的无质量连接器执行。
