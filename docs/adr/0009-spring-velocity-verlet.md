# ADR 0009：弹簧使用速度 Verlet 与自动内部子步

## 状态

已接受，随应用版本 `0.7.0` 实施；场景格式与 Worker 接口不变。

## 背景

旧实现只在每个 `1/120 s` 固定步开始时计算一次弹簧力，再把它作为普通外力交给 Rapier。这个推进次序对振子不是能量有界的辛积分：阻尼设为 `0` 时，两个小球的速度振幅和总机械能仍会随着运行时间持续增长。原有自动测试只检查一个周期后的相对位置，无法发现 300 秒量级的长期漂移。

给阻尼设置隐藏最小值只能把数值增能换成数值耗散；限制速度或总能量会掩盖真实碰撞与外力。Rapier 原生弹簧关节在当前二维版本、当前参数下还会产生本项目无法接受的无阻尼能量衰减，因此不用于替换现有弹簧实体。

## 决策

1. 弹性项采用二阶速度 Verlet：按步首锚点位置施加半步弹性冲量，由 Rapier 推进刚体、场力和碰撞，再按步末锚点位置施加后半步弹性冲量。
2. 阻尼 `0` 时不执行阻尼冲量。阻尼大于 `0` 时，根据两个锚点沿弹簧方向的有效逆质量，对相对速度施加指数衰减冲量；该冲量只能减少相对运动能量。
3. 局部锚点的世界速度包含刚体角速度。冲量施加在锚点而不是质心，因此有效质量、力矩和转动惯量都参与推进。
4. 刚体和碰撞体创建后立即刷新质量属性，保证关闭碰撞的小球在第一个物理步前也具有正确质量。
5. 对每条弹簧计算保守有效逆质量：

   ```text
   inverseEffectiveMass =
     1/m₁ + 1/m₂ + |r₁|²/I₁ + |r₂|²/I₂
   ```

   以 `ω = sqrt(k × inverseEffectiveMass)` 估计最高固有频率，并选择统一内部子步数，使 `ωΔt_sub ≤ 0.1`。弹簧、场、碰撞、地面路径和其他约束在同一个世界中使用相同子步时间线。

6. 一个对外固定步最多拆成 32 个内部子步。超过时，将该弹簧本次运行的有效刚度限制为稳定范围内的最大值，并通过现有警告系统显示原刚度和实际刚度；不修改实体属性或存档。
7. 运行时合外力仍按完整固定步前后的 `m·Δv/Δt` 计算，因此包含两个半步弹簧冲量、场力、碰撞和约束的合效果。
8. 新建弹簧默认阻尼为 `0 N·s/m`，让界面默认值与“无阻尼”物理语义一致。该默认值只作用于新实体；旧场景中的阻尼数值原样保留，`schemaVersion: 5` 不变。

## 后果

- 两个等质量自由小球以 `k=20 N/m`、阻尼 `0` 运行 300 秒时，总机械能误差保持有界且小于 `0.5%`，速度振幅不再持续增长或衰减。
- 不同质量、非零质心速度、非中心锚点、多个弹簧共享物体、地面路径接触和物体碰撞使用同一积分规则。
- 普通默认弹簧仍只执行一个内部子步；高刚度场景才按需要增加成本。20 对 `k=1000 N/m` 弹簧触发约 4 个内部子步时，本机最终独立复测 P99 为 `4.2964 ms`，低于每步 `8.33 ms` 预算。
- 极端刚度不再产生非有限状态，但运行时有效刚度可能低于用户输入；该差异必须可见，不能静默发生。
- 本决策不增加总能量图表，也不改变弹簧属性结构、`schemaVersion: 5` 或 Worker 消息格式；新建弹簧的默认阻尼改为 `0`，已有实体不受影响。
