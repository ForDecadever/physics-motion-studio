# ADR 0002：曲线地面的误差受控折线碰撞

状态：已采用<br>
日期：2026-07-21

## 决策

直线直接生成线段碰撞体；圆弧与三次贝塞尔曲线先自适应采样，再生成 Rapier polyline 碰撞体。默认最大几何误差为 `0.002 m`，最大线段长度为 `0.1 m`，最多 2048 段。

单面地面以点序的左法线为可碰撞面。物体从背面接近时，接触过滤器持续忽略该碰撞对，直到物体完全穿过曲线厚度范围；这可避免物体中心越过曲线后被错误弹回。

## 原因

- Rapier 没有直接接受任意贝塞尔曲线的解析碰撞体；
- 自适应采样能在平直区域减少线段，在高曲率区域增加精度；
- 同一组采样点可同时用于碰撞误差测试和法线方向判断；
- 设定线段数上限可防止异常曲线耗尽内存或阻塞初始化。

## 代价

- 曲线碰撞存在可量化但非零的离散误差；
- 极小物体或极高速度仍应开启 CCD；
- 后续加入曲线控制点实时编辑时，需要缓存并按修改范围重建碰撞体。
