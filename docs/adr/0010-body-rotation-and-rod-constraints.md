# ADR 0010：物体旋转锁与杆约束

- 状态：已采用
- 日期：2026-07-28
- 应用版本：`0.8.0`
- 场景格式：`schemaVersion: 6`
- 取代：ADR 0003 中的杆位置/速度投影方案

## 背景

旧杆求解器只按物体质量平移质心，再平均角速度。它没有把局部锚点力臂和转动惯量纳入有效质量，因此偏心锚点、不同质量、闭环和锁转物体会得到错误的力矩响应。仅把两个物体角速度设为平均值也不等价于固定关节。

小球和物块还需要一个明确的转动自由度开关。只把转动惯量设为零并不足以阻止显式非零角速度推进角度，因此数据、刚体自由度和自定义求解器必须使用同一语义。

## 决策

1. `BodyEntity` 增加必填 `rotationEnabled`。新物体默认为 `true`；`5 -> 6` 迁移只为旧物体补写 `true`。
2. 关闭旋转时使用 Rapier `lockRotations()`，运行时初角速度和全部自定义角速度写入显式设为 `0`。存档中的初角速度保留，以便重新开启旋转后恢复。
3. 曲面摩擦对锁转小球使用零逆转动惯量；摩擦只改变平动速度，不建立滚动角速度。
4. `freeRotation: true` 的杆使用双边距离约束：

   ```text
   C = |pB + rB - pA - rA| - L = 0
   ```

   有效逆质量包含两端沿约束法向的平动逆质量，以及 `(r × n)² / I`。锁转物体的逆转动惯量为零。
5. 每个内部物理子步在 Rapier 推进后最多执行 8 轮非线性位置 Gauss–Seidel，再执行最多 8 轮速度冲量求解；位置误差和锚点法向相对速度分别低于 `1e-6` 时提前结束。
6. 位置修正使用约束梯度同时修改平移和允许的转动。速度冲量施加在真实世界锚点，因而保持线动量并产生正确力矩。锚点重合时使用第一物体局部 X 轴作为确定方向。
7. 离散位置投影会改变按修正后位置计算的轨道角动量。对全部允许旋转的连通杆网络，求解器把修正前的角动量差投影到满足全部杆速度约束的整体转动零空间；该修正保持线动量和杆长，不设能量边界或速度限幅。
8. `freeRotation: false` 的杆使用 Rapier Fixed Joint。第二端采用虚拟间隔框架，使可见锚点保持配置长度而非被拉到重合；关节同时保持初始相对角度与完整相对位姿。

## 后果

- 锁转物体仍可平移，角度可编辑，模拟角速度和转动动能始终为零。
- 自由端杆支持拉伸、压缩、不同质量、偏心锚点、单/双端锁转、共享物体、链和闭环。
- 两体自由杆无外力运行 `300 s` 时，杆长误差小于 `1e-5 m`，总机械能漂移小于 `0.5%`，质心速度和总角动量保持稳定。
- 固定端杆具有真正的焊接语义；双自由物体可整体旋转，任一端锁转会约束整个刚性组合的整体旋转。
- Worker 的角度、角速度和能量输出结构不变。

## 依据

- [Box2D 固定旋转](https://box2d.org/doc_version_2_4/md__e_1_2github_2box2d__24_2docs_2dynamics.html)的语义通过清零转动惯量及其逆量实现自由度锁定。
- [Rapier 关节模型](https://rapier.rs/docs/user_guides/javascript/joints/)中的 Fixed Joint 删除两个刚体之间的全部相对自由度。
- 自由端杆的雅可比、有效质量和顺序冲量形式遵循 [Erin Catto 的顺序冲量约束方法](https://box2d.org/files/ErinCatto_IterativeDynamicsSlides_GDC2005.pdf)。
