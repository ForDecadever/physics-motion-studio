# ADR 0003：阶段 3 场力与连接器求解

- 状态：已采用
- 日期：2026-07-21

## 决策

匀强重力、电场、点电荷和弹簧由项目物理层计算并作为外力交给 Rapier。匀强磁场只改变速度方向，因此使用解析旋转更新速度，避免显式欧拉法凭空增加动能。

绳使用 Rapier 的最大长度关节。杆在每个固定步后使用质量加权的位置和法向速度投影，保证既能受拉也能受压。弹簧按 `F = k(ℓ-ℓ₀) + c·v_rel` 在两个局部锚点施加大小相等、方向相反的力。

运行时“合外力”统一由同一个物理步内的动量变化 `m·Δv/Δt` 计算，从而包含碰撞与关节冲量；禁止用相邻渲染帧的位置差估算。

## 原因

- Rapier 适合碰撞和绳约束，但二维 API 没有同时允许自由转动的刚性定长杆关节；
- 磁场力始终垂直速度，解析旋转可直接满足“不做功”的物理规律；
- 自定义弹簧便于统一胡克力、阻尼、局部锚点和力矢量口径；
- 固定物理步内计算合力比渲染帧差分稳定，且不受播放帧率影响。

## 边界

杆投影对中心锚点最精确；非中心锚点与复杂闭环机构属于迭代近似。极端刚度弹簧仍应减小固定步长，而不是无限提高劲度系数。
