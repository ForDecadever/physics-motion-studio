# ADR 0003：阶段 3 场力与连接器求解

- 状态：部分被取代；弹簧推进由 ADR 0009 取代，杆投影由 ADR 0010 取代
- 日期：2026-07-21

## 决策

匀强重力、电场和点电荷由项目物理层计算并作为外力交给 Rapier。匀强磁场只改变速度方向，因此使用解析旋转更新速度，避免显式欧拉法凭空增加动能。弹簧的力学口径仍由项目物理层管理，但长期积分方式改由 ADR 0009 规定。

绳使用 Rapier 的最大长度关节。杆原先使用质量加权的位置和法向速度投影；该近似没有包含非中心锚点的力臂与转动惯量，现已由 ADR 0010 的自由端双边约束和固定端 Fixed Joint 取代。弹簧仍遵循 `F = k(ℓ-ℓ₀) + c·v_rel` 并在两个局部锚点施加大小相等、方向相反的冲量；具体的速度 Verlet、阻尼和自动子步见 ADR 0009。

运行时“合外力”统一由同一个物理步内的动量变化 `m·Δv/Δt` 计算，从而包含碰撞与关节冲量；禁止用相邻渲染帧的位置差估算。

## 原因

- Rapier 适合碰撞和绳约束，但二维 API 没有同时允许自由转动的刚性定长杆关节；
- 磁场力始终垂直速度，解析旋转可直接满足“不做功”的物理规律；
- 自定义弹簧便于统一胡克力、阻尼、局部锚点和力矢量口径；
- 固定物理步内计算合力比渲染帧差分稳定，且不受播放帧率影响。

## 边界

杆约束的现行边界见 ADR 0010。弹簧的实时稳定范围和极端刚度处理见 ADR 0009。
