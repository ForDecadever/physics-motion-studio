# ADR 0033：有界运行记录与长时间性能验收

- 状态：已采用
- 日期：2026-08-23
- 应用版本：`1.6.0`
- 场景格式：`schemaVersion: 20`
- 关联：ADR 0003、ADR 0023、ADR 0029、ADR 0032

## 背景

旧画布轨迹在每个 60 Hz 运行帧中使用数组展开和尾部切片。即使轨迹点数已有上限，达到上限后仍要为每个物体和离子复制完整历史；整圆点源包含 1080 个离子，这一路径会随运行时间接近上限而显著增加分配、垃圾回收和 Pixi 线段数量。GIF 环形记录达到 300 秒后，样本数恒为 9000，旧的整除判断还会导致 Worker 每个采样帧重复发布相同状态。

图表和 GIF 已使用预分配数值环形缓冲，但画布轨迹、Worker 警告发布和接触状态还缺少统一、可测量的长时间口径。

## 决策

1. 物体和离子画布轨迹使用 `Float64Array` 分块组成的固定容量环形缓冲。追加点原地写入，不展开、切片或复制旧历史；满容时只覆盖最旧点。
2. 三个连续点在中间点到新弦线的距离不超过 `0.00025 m`、方向没有反转时，以新端点替换旧端点。渲染阶段按当前缩放再跳过距离小于半像素的短段，不为缩放重建或复制历史。
3. 每个物体最多保留 1800 点。单条离子最多 512 点，全部离子共享 65536 点；离子极端超量时均匀选取最多 32768 条可见轨迹，物理世界中的离子数量和运动不受影响。
4. 图表继续按场景采样率和时长预分配，GIF 继续以 30 Hz × 300 秒预分配。GIF 达到容量后仅在首次达到 9000 帧时发布状态，此后覆盖旧帧不重复通知。
5. Worker 只遍历新增物理警告，不在每个固定步创建空切片。主线程按稳定消息去重并只保留最近五条不同警告。
6. 接触流形不是时间历史：连接器流形每步删除未保留键，路径和布尔圆弧释放屏蔽在离开净空后删除；它们的最大规模由场景实体、碰撞段和当前接触对决定。公开只读诊断计数供长时基准核对，不把求解器对象暴露给界面。
7. 独立 `pnpm benchmark:long` 实际推进 1000 秒普通场景和 100 秒复杂场景，把物理、运行帧、轨迹、图表和 GIF 追加共同计时，比较首尾各 10 秒的平均值与 P99。两项相对退化都必须不超过 20%。

## 后果

- 达到轨迹容量后，每帧成本不再与历史长度成正比；1080 离子场景的轨迹数值存储保持在约 1 MB 量级，而不是数百万个 JavaScript 点对象。
- 轨迹是误差受控的运行可视化，不是无限精度的科研数据；图表/CSV 和 GIF 继续使用各自明确的采样记录。
- 1000 秒普通场景末段平均/P99 相对首段下降 `55.0%/92.5%`；100 秒复杂场景下降 `7.8%/28.6%`。复杂场景接触状态峰值 13，没有按运行步数增长。
- 超过 GIF 的离子上限仍明确阻止记录，不以丢弃离子或降低物理采样换取表面内存达标。
