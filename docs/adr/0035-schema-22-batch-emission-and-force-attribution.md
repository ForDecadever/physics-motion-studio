# ADR 0035：格式 22、批量连续发射与受力来源归属

- 状态：已采用
- 日期：2026-08-24
- 应用版本：`1.6.2`
- 场景格式：`schemaVersion: 22`
- 关联：ADR 0032、ADR 0034

## 背景

v1.6.1 的连续粒子源每个计划时间只发射一个角度或沿线样本，不能表达教学场景中“每隔一秒重复发射整束粒子”的行为。旧本机偏好还可能保存早期的 `0 C` 粒子源新建默认值，使新建对象与当前产品默认不一致。

测力计原先只能把最终合力残差合并显示为“连接器/接触/约束合力”。这能守住总量，但无法区分同一物体上的两根绳、两根杆或多个独立接触对象。

## 决策

1. 场景格式升级到 22。粒子源连续发射设置新增 `simultaneous`；格式 21 到 22 的确定性迁移把它设为 `false`，保持旧场景逐个发射的行为。
2. “同时发射”开启时，`t=0` 和此后每个绝对计划时间都生成完整确定性样本批次；关闭时继续逐个循环。粒子 ID 在批次之间仍单调稳定，寿命按各批次的准确出生时间清理，批量大小不参与下次发射时间计算。
3. 点源密度采用数量语义：非零角宽的粒子数为“角宽 × 密度”的四舍五入值并至少为两个；非整圆仍覆盖两个端点，整圆仍不重复首尾且服从 3600 个上限。因此 `180° × 3 个/度 = 540`。
4. 本机偏好升级到版本 3。版本 1、2 中遗留的粒子源新建默认电荷统一迁移为 `1 C`；版本 3 继续保存用户之后主动设置的零电荷。场景实体的既有电荷量不迁移。
5. 物理帧为当前接触保留来源实体 ID、来源类别和作用方向；连接器折线提供各物体端点处的当前方向。测力计先按既有公式得到已知外力，再把最终合力残差归属到每根连接器和每个接触来源。
6. 多来源归属采用确定性的最小范数方向分解；绳和接触的系数不得为负，杆和弹簧允许拉压。若来源方向不足以表达残差，未归属部分单列为“其他约束合力”。每一项都标明是推导值，不能声称它是 Rapier 内部单个求解器冲量。
7. 每个已成功建立的连接器都发布运行时端点或折线，不以质量和碰撞开关作为条件。单个来源只能取得残差在自身方向上的投影，不能吞掉垂直分量。无质量绳把圆球压在直线地面时，绳和直线接触继续由同一个原生约束步骤联合求解；解析地面持续接触不再二次覆盖该组合的沿线速度，曲面路径仍使用既有解析持续接触。

## 后果

- 用户可在同一个连续粒子源上选择逐个发射或整批同时发射，旧场景打开后行为不变。
- 新建粒子源在旧安装升级后也可靠使用 `1 C`，同时不覆盖场景内已有实验数据。
- 双绳、双杆、弹簧及多个地面/物体接触在面板和受力图中具有独立名称、颜色和箭头；所有分项加上余量严格回到最终合力残差。
- 默认关闭连接器碰撞的无质量绳也能提供实时方向；斜绳—直线墙面静止系统不再因两个求解步骤互相覆盖而隔步抽搐。
- ADR 0032 中“无法直接分离的响应只合并显示”的限制被本 ADR 的显式来源与推导归属取代；“不得把推导值伪装成原始观测量”的原则继续有效。
