# ADR 0022：碰撞绳长距离速度投影

- 状态：已采用
- 日期：2026-08-09
- 应用版本：`1.3.4`
- 场景格式：`schemaVersion: 10`（不变）
- 细化：ADR 0019、ADR 0020 与 ADR 0021 的碰撞绳约束顺序

## 背景

碰撞绳的位置阶段同时求解相邻绳段、双向长距离上限和整绳总弧长，但速度阶段只投影相邻绳段及总弧长。地面锚定单摆运行时，内部轻质量节点可以暂时收缩并抵消总弧长速度梯度，使摆球积累明显的径向分离速度；随后位置约束再集中拉回摆球，形成可见抽搐和非物理的支持力尖峰。

## 决策

1. 碰撞绳的每轮速度求解同时执行相邻绳段速度投影和双向长距离速度投影。
2. 长距离速度投影复用位置阶段的绳上距离上限、有效质量、正反向扫描与松弛判定，不增加新的经验长度或材料参数。
3. 约束仍是只阻止继续伸长的单边约束；不会把松弛绳推开，也不加入隐藏阻尼、速度限幅或能量裁剪。
4. 地面锚点单摆回归同时检查相邻固定步的速度连续性与沿锚点半径方向的分离速度，防止只靠最终位置掩盖延迟修正。

## 后果

- 拉紧碰撞绳的张力可在同一速度阶段传到总端点，摆球不再先径向外窜、数步后突然被拉回。
- 松弛绳的局部弯曲、地面锚点自接触豁免、绳长容差、存档字段与 Worker 运行折线接口均保持不变。
- 每轮增加一次现有长距离约束扫描，需要在连接器压力基准中继续验证固定步预算。
