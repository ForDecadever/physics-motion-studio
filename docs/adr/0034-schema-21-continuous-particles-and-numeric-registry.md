# ADR 0034：格式 21、连续粒子记录与受控数值属性注册表

- 状态：已采用
- 日期：2026-08-23
- 应用版本：`1.6.1`
- 场景格式：`schemaVersion: 21`
- 关联：ADR 0029、ADR 0031、ADR 0032、ADR 0033

## 背景

v1.6.0 的点源密度固定为每度约三个粒子，粒子只在物理世界初始化时一次性生成；GIF 记录又以固定宽度数组和 512 个离子上限为前提。加入连续发射后，粒子会在不同帧出生和到期，固定宽度记录既不能稳定匹配同一粒子，也会迫使物理数量服从导出限制。

属性表达式原先只覆盖少量枚举字段。扩大覆盖面时若允许任意对象路径，会绕过场景类型、单位换算和验证；如果为每个属性各写一个输入框，又会重复引入步进丢失、公式和单位重叠、草稿切换丢值等问题。电场总大小公式和力方向弧度公式也与 v1.6.1 的界面口径不一致。

## 决策

1. 场景格式升级到 21。格式 20 到 21 迁移为粒子源补默认密度、连续开关、间隔和寿命；把旧电场大小公式沿原方向拆成 X/Y 分量；把旧力方向弧度公式乘以 `180/pi` 转成度表达式；把旧表达式键映射为注册表键。迁移不得改写旧场景的电荷量或用户保存的新建默认值。
2. 点源把 `densityPerDegree` 保存为场景属性，范围 `0.01～10`。非整圆包含两端，整圆不重复首尾，粒子数最多 3600。新建粒子源的默认电荷为 `1 C`。
3. 两种粒子源共享确定性连续调度：`t=0` 首发，之后按绝对计划时间每个间隔发射一个样本；点源循环角度样本，线源循环沿线样本。粒子保存稳定 ID、源参数、出生时间和连续标记；寿命到期立即移除。重置必须重现同一序列，不能用逐步累加的下一次时间制造长期漂移。
4. 连续粒子不建立主画布轨迹，GIF 同样只绘制位置。关闭连续模式时保留原批量粒子和轨迹语义。
5. GIF 粒子记录使用稳定 ID、帧偏移和分块环形存储表达变长集合，插值不得跨越出生或到期边界。删除 512 个粒子上限；刚体 200、连接器节点 512、像素帧 500,000,000 和编码输出 512 MiB 的既有边界保持不变。
6. GIF 运行遥测使用公开的 512 MiB 总预算。达到预算时只淘汰最旧记录并提示可导出时间范围，不删除当前活动粒子、不降低物理精度，也不停止模拟。
7. 属性表达式目标由受控数值属性注册表声明。每项注册路径、显示单位、SI 转换、合法范围、步长和是否允许 `t`；存档校验只接受注册键，禁止任意路径访问。画布直接变换受公式控制的值时，命令原子清除相应绑定并写入字面值，撤销同时恢复绑定。
8. 属性栏统一使用公式数值输入：文本、单位和解析值分区；保留上下箭头及键盘步进，默认按显示单位加减 1；公式步进规范化为一个外层偏移。新工具接入注册表后复用相同的变量、校验、单位和待提交草稿行为。
9. 电场只暴露 X/Y 分量及各自表达式。某一步任一分量非有限时停用对应场并去重告警。力静态方向继续以 `directionRad` 保存，界面和方向表达式统一使用度，运行时换算为弧度。
10. 本机偏好固定为暗色版本。删除主题字段、浅色令牌和系统主题监听，旧偏好迁移为暗色；这不进入场景格式或撤销栈。
11. 软件说明提供与发布版本一致的内置 PDF 打开与下载入口；生成脚本、发布副本和交付 PDF 同源，发布前逐页渲染检查。

## 后果

- 连续源的活动粒子数量由寿命和间隔自然界定，不随总模拟时间无界增长；粒子物理规模不再被 GIF 导出能力反向限制。
- GIF 可以记录 1080、3600 个静态粒子和跨帧出生/到期的动态粒子；预算收缩只改变历史起点，并向用户公开实际范围。
- 场景数值属性获得一致的全局变量、公式、单位与步进行为，同时保持路径白名单和 SI 存储边界。
- 格式 21 的迁移必须用往返、非法范围、电场分量和力方向等价性测试守住；格式 11 或更早的旧图层结构继续拒绝读取。
- ADR 0031 的少量表达式目标和 ADR 0033 的固定 300 秒粒子记录/512 粒子上限，由本决策中的受控注册表和预算型变长粒子记录取代；其余安全解析和有界运行历史原则继续有效。
