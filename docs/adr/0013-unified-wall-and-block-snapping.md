# ADR 0013：统一墙面与物块表面吸附

## 状态

已接受。应用版本升级为 `1.2.0`，场景格式继续使用 `schemaVersion: 7`。

## 背景

编辑器原有网格吸附和可选墙面吸附，但创建、移动物体时不能直接贴合现有物块。若将物块吸附简单串在墙面吸附之后，结果会受执行顺序影响；旋转物块的角点也不能用轴对齐包围盒正确表达。

## 决策

1. 编辑器增加默认开启、仅在当前会话生效的 `blockSnapEnabled`。该状态不进入场景、撤销栈或物理 Worker。
2. 网格先确定物体初始位置，墙面和物块再进入同一个候选求解器，按实际修正距离选择最近结果。等距离时保留场景顺序，防止鼠标移动时目标闪烁。
3. 地面继续使用曲线采样后的线段最近点；物块使用旋转矩形的最近边界点和外法线。小球使用半径，物块使用当前角度沿接触法线的支撑半径。
4. 物块直边形成面接触，角点按欧氏方向相切。浅层重叠可在固定 `12 px` 屏幕阈值内向外修正，超过阈值的深层重叠不吸附。
5. 目标必须可见且位于可见图层；锁定但可见的目标仍可使用。移动时排除自身和同组对象，多选只由鼠标抓住的锚点求解，再将同一修正应用到整组。
6. `Alt` 同时绕过网格、墙面与物块吸附。旋转、对象缩放、控制点编辑和运行中的物理模拟不使用表面吸附。
7. 吸附只改变编辑预览与最终放置位置，不建立关节或持久约束，也不修改质量、角度、尺寸和模拟参与状态。
8. 布尔结果整体移动复用同一候选求解器，但支撑距离来自派生多边形的全部外环；孔洞不作为外表面，多岛与凹形不能用包围盒代替。布尔来源子树全部排除，求得的修正位移原子应用到所有后代。墙面和普通旋转物块继续分别服从既有开关，其他布尔结果不作为物块吸附目标。

## 结果

- 墙面和物块没有固定类型优先级，组合开启时结果可预测。
- 旋转物块的边与角点按真实碰撞轮廓参与吸附。
- 统一求解器是纯几何函数，可独立覆盖退化、排除、缩放阈值和大候选集合性能。
- 布尔结果与普通物体共享候选排序、`12 px` 阈值和 `Alt` 绕过语义，同时保持来源间相对位置和单条撤销记录。
- `snapBodyToGround` 保留为兼容包装，旧调用与既有地面回归继续有效。
