# ADR 0006：统一地面路径与持续接触约束

## 状态

已接受，随应用版本 `0.7.0` 和场景格式 `schemaVersion: 5` 实施。第 3 条中的任意夹角发卡过渡后来被 ADR 0007 的受限夹角与端点配对规则取代；其余统一路径和持续接触决策继续有效。

## 背景

此前圆弧同时存在三套几何：Pixi 的解析绘制、Rapier 的折线碰撞，以及仅对无摩擦小球启用的解析圆周投影。Rapier 的折线位置修正可能让球心暂时越过解析投影的 `0.003 m` 接触阈值，使解析约束退出；后续重新落回折线时又会收到额外冲量，表现为非物理的速度与加速度尖峰。

旧地面连接点只允许切线差不超过 `5°` 的端点交接，因此无法表达用户可见、具有有限曲率的锐角过渡。

## 决策

1. 建立统一的二维地面路径层。直线、解析圆弧、三次贝塞尔和连接点生成的过渡曲线都提供长度、位置、切线、法线、曲率、最近点、裁剪和误差受控采样能力。
2. 显示层、Rapier 碰撞采样和小球持续接触约束使用同一个解析后的地面网络，不再分别推导连接几何。
3. 地面连接点不再限制夹角。连接点裁剪两侧原地面并生成可见的有限长度 `G2` 过渡；普通转角使用五次贝塞尔，接近反向的转角使用双段发卡形过渡。连接点仍是只能推、不能拉的普通地面，所需支持力为负时物体必须脱离。
4. Rapier 继续负责首次撞击、物块、非路径物体和其他碰撞。开启碰撞的小球在真实接触后进入持久路径状态，并按弧长沿地面网络推进。
5. 活动小球与当前路径碰撞体之间使用 Rapier `PhysicsHooks` 返回 `SolverFlags.EMPTY`，保留接触流形但关闭折线求解冲量；其他碰撞对继续返回 `COMPUTE_IMPULSE`。在 Rapier 0.19.3 中必须通过 `world.step(eventQueue, hooks)` 才能实际执行这些钩子。
6. 路径状态不再要求每帧存在 Rapier 求解接触。负支持力、主动分离、走出未连接端点或无效偏置曲率会解除约束；解除后只有新的真实接近接触才能重新进入。
7. 非零摩擦路径使用接触点滑动速度、实际支持力、有效逆质量和有效转动惯量计算库仑摩擦冲量，使滑动连续过渡到滚动。
8. 图表继续显示由 `m·Δv/Δt` 得到的真实总加速度。不得对数据做平滑或限幅来隐藏求解问题。

## 后果

- 任意非退化夹角都可以生成可见的圆滑连接，并在物理允许保持接触时无接缝冲量地通过。
- 圆弧、贝塞尔和连接过渡共享持续接触逻辑，避免继续增加形状专用补丁。
- 路径求解器需要维护小球接触状态、曲面邻接和 Rapier 精确碰撞对过滤，复杂度高于只使用折线碰撞；因此必须为首次撞击、第三物体、CCD、脱离和重新接触保留独立回归测试。
- 当前自适应采样误差、最大段长及双面地面策略保持不变；本决策不增加全局曲线画质或随缩放细分设置。
