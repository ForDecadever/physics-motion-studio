# ADR 0015：连接器端点、质量与碰撞

- 状态：部分被 ADR 0017 取代
- 日期：2026-08-02
- 应用版本：`1.1.0`
- 场景格式：`schemaVersion: 8`
- 取代：ADR 0010 中杆的统一 `freeRotation` 布尔语义

## 背景

旧连接器只能引用两个物体局部锚点，杆的一个布尔值同时控制两端，连接器本身没有质量或碰撞。这个模型无法表达墙面固定端、单端焊接杆、固定世界点弹簧，也无法让杆、绳或弹簧成为可碰撞的物理实体。

高速地面过渡还存在另一类重复求解：解析路径已负责球心沿曲线推进时，Rapier 的相邻折线碰撞体仍可能在同一步内施加额外冲量。过短的自动过渡会放大曲率峰值，使高速运动的单步转角明显可见。

## 决策

1. 连接器端点改为联合类型：物体局部锚点、普通地面弧长位置、地面连接段弧长位置，以及仅弹簧可用的固定世界点。
2. 绳和杆的物体锚点始终夹在小球或物块轮廓内；弹簧锚点越界时转换为同一世界坐标的固定点，并允许重新吸附到物体或地面。
3. 杆的 A/B 两端分别保存 `free` 或 `fixed`。无质量双自由杆使用理想距离约束；单固定端增加相对方向约束；双固定端保持完整相对位姿。有质量杆使用动态胶囊，并在每端分别建立 Revolute 或 Fixed Joint。
4. 所有连接器增加碰撞、半径、质量和材料。`0 kg` 表示真正的理想无质量约束，不使用极小质量代替；碰撞冲量按接触点在线段上的比例传回端点。
5. 有质量绳和弹簧使用动态柔性节点。该条的具体柔性约束求解方式由 ADR 0017 取代；这些节点参与重力、接触和惯性，但不参与电磁场或静电作用。
6. 相邻分段和连接器自身端点物体之间不碰撞。单连接器最多 64 段，全场景最多 256 段；达到上限时明确警告并降低几何密度，不修改存档中的物理参数。
7. 自动地面过渡与无质量连接器—地面接触的后续修正由 ADR 0016 取代；活动路径按精确边界时间跨段，并关闭当前段及本步可达相邻段的重复折线冲量仍然保留。
8. 曲率和行程与弹簧共同决定统一内部子步：单步切线转角不超过 `0.025 rad`，球心行程不超过半径的四分之一，上限为 32。达到上限只警告，不限速或裁剪能量。
9. Worker 运行帧记录连接器节点，画布、命中检测和 GIF 导出共用该几何。GIF 最多记录 512 个运行时连接器节点，超出时停止记录并明确提示。

## 后果

- 旧 v7 连接器迁移为物体端点、无质量和无碰撞，旧场景行为不变。
- 世界端点弹簧默认开启碰撞的旧约定已由 ADR 0018 取代；格式 10 中所有弹簧都关闭普通碰撞并固定为零质量。
- 删除实体端点会级联删除连接器；世界端点随复制粘贴偏移。
- 高速小球可跨越直线、过渡和圆弧边界而不接收接缝反射；负支持力时仍会按物理规律离轨。
- 带质量柔性连接器的计算成本高于理想约束，因此分段上限和可见警告属于实时模拟的明确边界。
