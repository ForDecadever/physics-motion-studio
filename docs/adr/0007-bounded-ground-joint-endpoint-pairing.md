# ADR 0007：受限地面连接与端点配对

## 状态

已接受。场景格式继续使用 `schemaVersion: 5`。

## 背景

ADR 0006 为接近反向的地面使用双段发卡过渡。该算法为了寻找有限曲率解会主动扩大侧向尺寸，在极小或极大夹角下可能生成看起来接近整圈的异常路径。旧手动工具还要求两个端点间距不超过 `0.003 m`，无法直接选择两个相隔一定距离的端点。

## 决策

1. 手动工具采用明确的两次点击：先选择端点 A，再选择另一块地面的端点 B。两个端点可以相隔一定距离；悬停 B 时使用临时路径网络显示有效或无效预览。
2. `≤1°` 的近同向连接无效，软件不创建连接实体。
3. `1°～179°` 只使用五次过渡。候选必须满足有限导数、曲率、长度包络、累计转角和无自交检查；只允许有限次缩短裁剪量和控制柄，不得扩大尺寸寻找绕行解。
4. `≥179°` 直接使用两个原始端点之间的直线，不裁剪两侧地面；端点重合导致零长度直线时连接无效。
5. 删除双段发卡兜底和属性栏的方向翻转控件。旧场景中的 `directionFlipped` 字段继续保留但不参与求解，避免升级场景格式。
6. 自动连接与手动连接共用相同几何验证；自动连接仍只在新地面起点进入既有端点的 `10 px` 范围时触发。

## 后果

- 极端夹角不会再生成发卡弯、环形路径或对应的隐藏碰撞折线。
- 分离端点可由一条真实可见、可碰撞的连接路径补齐。
- 普通五次过渡求解失败时会明确提示用户重新选择端点，不再用形状更复杂的曲线掩盖失败。
- `≥179°` 的直线规则优先保证形状简单和可预测；由于两端切线近乎相反，它不承诺接缝处的切线或加速度连续。
