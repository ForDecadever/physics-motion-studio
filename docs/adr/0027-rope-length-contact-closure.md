# ADR 0027：碰撞绳长度—接触闭合与进入侧保持

- 状态：已接受
- 应用版本：`1.4.1`
- 场景格式：`schemaVersion: 10`（不变）
- 补充：ADR 0026 的统一碰撞绳 XPBD 求解顺序

## 背景

ADR 0026 将碰撞、逐段长度、长距离张力和整绳弧长纳入统一批次，但速度重建之前仍保留了一次不刷新接触的完整绳长收敛。该步骤可能把已经推出圆球或物块的活动节点重新拉到障碍物另一侧。删除该步骤后，还必须让地面接触继续获得足够的长链收敛预算，并避免全局总长投影与刚体表面的局部绕行相互争夺。

## 决策

1. 任何绳长投影前保存运行绳段的端点；投影后只对实际移动超过位置容差的绳段执行连续扫掠，并复用现有两级宽相候选。
2. 每轮顺序固定为“绳长与张力—局部扫掠和流形刷新—接触位置投影”。退出条件同时检查绳长和穿透，最后一个位置操作必须属于接触投影。
3. 删除速度重建前的额外完整绳长收敛。纯地面接触的统一循环可用内部节点求解总弧长；存在刚体接触时，总弧长修正只向真实端点传递反作用，内部节点继续由逐段和长距离约束收敛，避免全局投影把局部绕行节点推入障碍物。
4. 持续接触保存进入法线。未先分离、也没有新的物理扫掠时，不接受突然翻转到障碍物另一侧的法线；圆球表面相近法线仍可连续旋转。
5. 首次接触使用局部相邻节点以形成柔性弯曲。同一接触被后续绳长修正再次激活时，只有当障碍物的方向逆质量不小于整绳端点约束逆质量，才使用整绳端点有效质量传递位置反作用；大质量障碍物仍允许绳的局部节点沿表面绕行。
6. Rapier 预测运动产生的新撞击按材料执行一次弹性响应；绳长位置投影发现的接触只阻止穿透，不增加弹性冲量。位置迭代预算为 `clamp(4 × 自适应分组数, 8, 32)`；预算耗尽且仍有穿透时，最多再执行四次纯接触投影，优先保持非穿透并通过现有警告报告残余绳长误差。
7. 旋转物块使用 Rapier 的真实胶囊接触点。法线可能翻侧时，以进入法线对应的凸体支撑平面检查绳段两个端点中更危险的一端，不能用物块中心最近点近似整段是否已离开。

## 结果

- 地面锚定摆绳持续绕过圆球或旋转物块时，每条胶囊段都保持在原进入侧，残余穿透不超过 `0.002 m`。
- 低质量绳的逐段与总弧长容差、无摩擦能量口径和局部弯曲行为继续成立。
- 无接触绳仍走快速路径；局部重扫不遍历整个场景，也不增加节点密度或隐藏阻尼。
